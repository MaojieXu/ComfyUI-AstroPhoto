# 素材、项目与校准

素材目录管理子帧组、视频、主帧和图像结果；项目以逻辑树引用已登记素材。存储位置、文件迁移与恢复见[存储](storage.md)，设备及组合见[设备](equipment.md)。

## 导入和文件所有权

复制导入将文件写入受管位置；引用登记保留外部原文件路径。子帧组保留成员、顺序和每个文件的位置。导入按实际位置、容量和任务状态处理，失败或暂停的处理及重试见[存储](storage.md)。

素材登记、修改或移除成功后，宿主向已连接的前端发送变更通知；素材侧栏和已打开的来源节点重新读取数据，连接恢复时也重新读取。已选素材被移除时节点保留原选择并提示用户重新选择，未保存的输入不会因后台刷新被覆盖。

## 项目与校准

项目目录是逻辑组织，不是文件系统目录；移动或移除项目引用不删除原文件。校准用途主帧共用素材身份，子帧组可绑定适用主帧。参数或设备差异和未知值作为提示，不因差异或未知阻止绑定；温度仅保存登记值，不参与差异比较。设备组合和滤镜按绑定时的快照保留历史。

在 ComfyUI 画布使用以下素材节点。素材库和项目树中的单文件、子帧组可拖入画布；项目树内部拖放继续用于移动引用。

| 节点 | 输入与输出 |
| --- | --- |
| 文件来源 | 选择已登记素材，或填写宿主文件的绝对路径。节点执行时检查可读性，并输出 `IMAGE_PATH` 和聚合输入。 |
| 文件夹来源 | 选择宿主文件夹时提供 `FOLDER_PATH` 和聚合输入；选择子帧组时按登记顺序提供组成员，连接文件聚合节点以生成目录。 |
| 文件聚合 | 连接一个或多个聚合输入，复制单文件、组内成员及目录第一层文件，输出 `FOLDER_PATH`。 |

文件夹中的子目录不会展开。重名时在最后一个扩展名前加 `_2`、`_3` 等后缀，避开已存在的输入名称。工作目录和来源对应记录保存在处理 Cache，占用其额度，并在当前工作流结束时清理。源文件保持原位，处理中断和复制错误不会产生可连接的部分结果。文件夹输出只在当前工作流内有效。

删除素材会清理登记及相关项目、校准和来源关联。存在关联时，先展示影响并取得用户同意。删除受管文件，保留外部原件。从项目中移除素材仅移除项目引用。文件保护和重试规则见[存储](storage.md)。

## 接口与验证边界

前端通过宿主公开 API 管理目录；MCP 通过公开接口提供工具，连接与信任边界见 [MCP](../integrations/mcp.md)。按用途查找[目录与项目 HTTP 接口](../api/http/contracts.md#素材目录校准与项目)及[MCP 素材工具](../api/mcp/contracts.md#素材导入和校准)。集合节点遵循当前已登记的工作流契约，节点专项按后续计划核对。

素材及设备闭环和 Agent 管理的历史验收范围分别见[素材闭环关闭记录](../../.agents/features/archive/2026-11-24-03-asset-equipment-storage-integration/07_CLOSE.md)及 [Agent 管理测试报告](../../.agents/features/archive/2026-11-25-04-agent-asset-management/06_TEST_REPORT.md)。真实第二物理卷未在后者验收中覆盖；历史结果不代表当前工作树重新通过。
