# 本地存储与工作区 · 交互规格

**版本** v1.1 · 2026-11-21 · 交互与验收规格。下文先记录变更前的 Vue 基线。证据为组件与测试源码。历史 React 与已留存的宿主截图、测试记录各自维持原适用范围。

## 入口与可见状态

在 ComfyUI 左侧打开 AstroPhoto → Settings → Storage。当前 Storage 卡显示 Data Root 路径和来源、资产库健康、默认导入模式、工作区、迁移回执与 Cache。Settings → System Status 提供独立的储存可用性和启动诊断。首次等待显示加载状态，GET 错误提供 Refresh。写能力关闭或本页已有动作时，变更入口禁用。保存后重新读取服务端快照，冲突提示可刷新；Cache 草稿可在刷新后保留。 [StoragePage.vue](../../../frontend/src/features/storage/StoragePage.vue) · [SettingsPage.tsx](../../../frontend/src/features/sidebar/SettingsPage.tsx)

| 场景 | 前提、动作与结果 |
| --- | --- |
| FR-01 初始化/诊断 | 进入 Storage 读取快照。显示根路径和数据库状态；读取失败显示错误与刷新，亦可去 System Status 查看可用性。 |
| FR-02 登记与默认 | 展开 Add workspace，填名称和服务端绝对路径后保存。已登记行显示名称、路径、状态、容量和默认徽记。操作面板可验证、启停、改名，在线非默认项可设为默认；结果刷新，验证有文本通知。 |
| FR-02 / FR-04 迁移 | 在线行打开 Migrate workspace，原生输入框提交目标路径，取消输入框不提交。服务端拒绝后显示错误。受理后显示 ID、阶段和可取得的计数、验证方式及错误；后端轮询失败给刷新入口，非终态支持取消，收到非终态错误时可申请重试。终态继续呈现回执，刷新行路径以快照为准。 |
| FR-03 模式与 Cache | 选择 Reference 或 Copy，按服务端刷新值高亮。Cache 展示使用量和状态，编辑路径或限额后保存。在线时可打开清理确认；确认框含当前路径，取消无请求，确认后显示删除数量、字节、跳过和失败数。 |
| FR-05 重绑与解除 | 当前 UI 在离线、标记不匹配或禁用时提供重绑路径输入，服务端仍检查原标记、目标身份与租约。移除需宿主确认，默认项与迁移中项禁用，资产或活动任务拦截由服务端反馈。 |

## 反馈、键盘与待验收项

评审时按三个独立入口走查。更改默认后以服务端快照的默认徽记为准，旧行路径应保持原值。使用重绑时输入已移动的目录，原行 ID 保持，只有成功后才显示新路径。迁移受理后继续展示作业阶段，待服务端提交和刷新才改变行路径。遇到离线或身份不符时，保留原工作区和默认徽记，用户可恢复原路径、按条件重绑，或另选在线工作区用于后续作业。请求失败时保留服务端确认的值。真实宿主还需复核离线回到在线、非终态错误后重试和刷新找回回执。 [Q-02、Q-04](01_PRD.md) · [CASE-04～05](05_TEST_PLAN.md)

Workspace 更多动作按钮有名称、展开状态和控制关系，Escape 收起并返回按钮焦点。单选和表单使用 HTML 原生控件，迁移、改名、重绑和清理确认复用宿主对话框。状态含文本，验证/清理回执使用 status 区域，文案来自英/中词条，Theme 由侧栏样式接入。真实宿主中需复核窄侧栏、长路径、键盘对话框回焦及错误宣布。 [WorkspaceActions.vue](../../../frontend/src/features/storage/WorkspaceActions.vue) · [OperationProgress.vue](../../../frontend/src/features/storage/OperationProgress.vue) · [CacheSettings.vue](../../../frontend/src/features/storage/CacheSettings.vue) · [英文字词条](../../../frontend/src/i18n/locales/en/sidebar.json)

当前发起迁移只有路径输入，容量和清单在服务端受理后检查。页面从快照取第一笔迁移或本页新启动的一笔。D-08 已确认新入口的预检、进度和最近一笔。离开 Storage 子页或卸载侧栏会清理该组件的轮询与请求。只切换侧栏标签可能保留已访问的 Settings 实例；后端任务仍可由 ID 查询。原型和宿主实测沿用历史材料；本轮未运行浏览器。 [历史交付](../../../docs/local-storage.md) · [历史 UI 资料](../../archive/storage-comfyui-frontend.md) · [CASE-01～05](05_TEST_PLAN.md)

## v0.5 界面设计历史

建议普通入口只展示当前存储位置、可用状态和导入操作。选择复制时显示副本位置，选择引用时提示文件留在原处。将全实例「搬家」和单行「迁移工作区」分别放到实例与工作区层级。正式的搬家原型还需评审预检、停止并重启宿主、失败回到原根和最近一笔回执。当前 Assets 页面为占位。 [FR-06、FR-07 与 Q-04、Q-06](01_PRD.md)

## v0.8 已确认的交互目标（历史）

打开本机可直接使用符合条件的存储能力，分动作显示不可用原因。目标缺失、不可写或不足时提示恢复或配置工作区。搬家提供整库/部分、预检、进度条与最近一笔。磁盘显示已用、限额与物理余量。Cache 页面优先提示临时文件随会话清理，目录换址保留旧根仅为现有能力。v1.1 由 StoragePage、WorkspaceActions、CacheSettings 和 OperationProgress 实现。 [PRD 决策](01_PRD.md)

D-15 确认工作区迁移的预检应说明成功后自动清理原位置已搬走的副本，后续无需再次确认。回执区分复制、切换与清理结果；清理受阻时显示新位置和剩余项。 [PRD 决策](01_PRD.md)

## v1.1 现行交互

**阶段** PH-02 DRAFT，产品决定已确认，界面与宿主交互待评审。当前 Vue 行为见上文。[本地交互原型](prototypes/storage-review.html) 可展示按量预检、确认、回执、同卷配额与手动换盘的关键状态，使用模拟容量和回执。整库实际停机、文件选择器及宿主退出钩子的原生接入仍需对照目标宿主验证。

| 入口与追踪 | 看到什么、可以做什么 |
| --- | --- |
| Settings → Storage → Data Root · FR-01/06 | 显示当前实例路径与诊断，入口「搬家 AstroPhoto」独立于工作区。预检列出 SQLite、配置、根内受管副本和正式输出，以及仍在原处的根外 Workspace 与 reference。提供停止宿主、执行停机工具、照常启动、自动打开新根并查看回执的步骤。新根启动验证失败显示是否可安全用旧根恢复；已有新根写入时提供重新搬回或备份恢复说明。旧根保留。 |
| Settings → Storage → Workspace · FR-02/05 | 保留 Add、验证、改名、默认、启停、重绑、解除登记。名称、当前目录、默认状态、磁盘/卷及检查错误各有文本。离线或只读的默认项继续显示；提供恢复、重绑及手动设默认入口。重绑发现缺件时先展示缺失清单，确认后显示「部分可用」；身份不符时保留原登记并提示原因。帮助文字说明合法解除只移除登记。 |
| Workspace → 完整迁移或按量迁移 · FR-02/04/06 | 完整迁移录入空目标目录，按量迁移选择另一个已登记 Workspace，录入百分比或 GB。百分比提示以此来源 Workspace 已登记受管的数据量作基数，外部 reference 与会话临时数据排除。两种模式均预检后确认，回到表单时保留输入。 |
| Storage → 磁盘容量 · FR-08 | 每卷一行，显示可关联的 Workspace、配额、已用、预留、剩余额度、系统可用。配额保存使用修订冲突提示。容量不足给出所需、可用和不足类别，并列可手动切换的工作区。改变默认后用户重新发起，原操作目标不会被改写。 |
| Storage → 作业 · FR-04 | 显示活动、等待与最近回执，按作业 ID 查找。列表显示源、目标、模式、阶段与结果；明细显示估算/请求量、已提交/未迁移量、清理残留与分组权威位置。取消请求先显示「正在取消」，待服务端确认后更新。停止轮询或关闭页面后仍能找回迁移。 |
| Storage → 会话临时文件 · FR-03 | 显示使用量和会话预算，达到上限提示减少需求或调整可配置额度。说明正常退出清理，意外退出在下次启动安全回收。失败或中断的未提交诊断随 Cache 清空。历史路径中可识别的 AstroPhoto Cache 纳入清理，其它文件保留。两窗口设置冲突保留草稿并显示最新快照。 |
| Assets → 导入 · FR-03/07 | 当动作可用，用户直接选择明确文件/目录；reference 提示原件留在原处，copy 显示目标 Workspace 与副本位置。无额外授权或来源白名单步骤。权限、来源不可读、离线、配额不足各有反馈；素材批次重复策略和导入选择器归素材专题。 |

### 预检、确认及回执状态表

| 条件 | 显示与动作 | 下一状态 |
| --- | --- | --- |
| 未填写、字段无效、预检中 | 就近标出字段；保留已填信息，预检请求在途防重复，返回仍可保留输入。 | 空态、阻断或可确认 |
| 目录/标记/登记异常或空间不够 | 显示具体路径、冲突和下一步，禁止确认不可执行结果；同卷显示「这次迁移不会增加该磁盘的可用空间，复制过程中还需要临时空间」。 | 更换目标或重新预检 |
| 按量恰好达到 | 显示来源基数、请求量、拟迁组及各组文件范围、预计量和清源清单。 | 确认迁移 |
| 只能接近请求量 | 不预选结果。分别显示「接受少搬 2 GB，迁移 8 GB」和「允许多搬 2 GB，迁移 12 GB」这类含数字的操作。超量不可行则显示原因，基础方案为空不允许确认。 | 用户选择后确认所选清单 |
| 点击确认时清单失效 | 提示「文件或目标容量已变化，请重新预检」，保留原输入，清除旧结果选择。 | 重新预检 |
| 已受理 / 活动 / 等待 / 取消中 | 显示作业 ID。阶段和实际处理量分别展示，进度未知用文本，不用百分比推算。允许安全阶段申请取消，底层只读、离线或容量错误同时显示。 | 回执或恢复 |
| 已提交 | 文案明确「数据已切换至新位置」，清理中另列。D-15 自动清理已成功迁走的受管副本。 | 完成或有待清理项 |
| 已提交但清理受阻 | 展示新位置、遗留项与原因，提供「重试清理」。未提交作业残留则提供独立预览及确认。部分迁移停止时，同时列出已迁与未迁范围。 | 继续清理或留存回执 |

复用现有 Sidebar/Settings 入口、语言字典和主题变量；具体控件由宿主支持情况核实。方案用原生可聚焦字段，结果选择以明确单选和文字表达，窄侧栏长路径折行且可复制，Escape 关闭对话并恢复入口焦点，摘要错误聚焦且只播报必要阶段变化。完成原型评审后，要在真实宿主检查键盘、读屏、窄侧栏、双窗口冲突和刷新回执。 [原型](prototypes/storage-review.html) · [验收](05_TEST_PLAN.md)

## Pi 评审补充 · 启动、状态与恢复

- **整库搬家。** 用户可以在 Storage 预检目标路径。确认停机后按提示执行 PowerShell 命令，普通启动从有效根打开。搬家回执提示照常启动即可自动打开新根。
- **工作区状态。** 在目标规格中分别显示「作业：迁移中」与「存储：卷离线／只读／身份不符」。文件详情沿用已有 availability，工作区级缺失汇总和 copy 目标选择控件是新增。卷未设配额时显示「未设配额」及实际可用空间，可直接写入。
- **标记与重绑。** 解除登记的确认文案提示标记和磁盘文件保留。原路径不可用时才尝试重绑，展示新位置核对的标记、卷及已登记文件差异；身份有效时可确认降级重绑。可用资产和正常写入入口继续开放，补回文件后可复检。
- **按量预检。** 空的不足方案不显示。只有超额可执行时，仍需明确选择最小可行超额并确认。低于名义最小超额所需空间时显示无法采用该组；若有其他可行候选则展示实际最小可行方案。输入/目标变化要求重新预检。
- **作业反馈。** 忙碌状态明确显示等待或需用户处理。失败/取消终态提供「重新预检并新建作业」，响应丢失可找回同一次提交。完整迁移提交后隐藏取消；已提交的清理残留展示「重试清理」，按量剩余组仍可在安全点取消。
- **恢复反馈。** `RECOVERY_REQUIRED` 显示阻断检查与可操作下一步：可证明属于本次任务的遗留项进入预览和显式清理，身份或配置不一致则引导检查路径、备份或诊断。 `WORKSPACE_IDENTITY_MISMATCH` 引导恢复原盘或核对重绑条件。源文件变化保留表单并要求重新预检。材料无法证明归属时告知保留，不提供批量删除。
- **容量单位。** 磁盘配置和迁移以十进制 GB 展示，保留的旧 Cache 预算按实际 GiB 解释。独立 HTML 使用模拟数据，仅验证交互。
