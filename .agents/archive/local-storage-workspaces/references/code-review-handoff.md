## 实现入口和重点

- **Data Root 与启动**。从 `__init__.py`、`astrophoto/bootstrap.py` 追踪到 `astrophoto/storage/data_root.py`、`runtime.py`、`initializer.py`。检查实例锁、停机搬迁、启用新根、回退及异常重启。
- **工作区与迁移**。检查 `storage/locations.py`、`migration.py`、`operations.py` 和 `api/storage.py`。覆盖预检、按量及完整迁移、提交前后中断、幂等、已提交源文件自动清理、清理失败重试、重绑及缺件。
- **容量与生命周期**。检查 `storage/capacity.py`、`cache.py`，以及素材导入和 Siril 正式输出的调用链。关注同卷共享额度、无配额时的可用空间、并发预留、退出清理和已提交文件的保护。
- **用户入口和契约**。检查 `frontend/src/features/storage/`、`frontend/src/api/storage.ts` 与对应后端路由，核对预检、确认、回执、重试和错误反馈。另核对素材与设备对工作区的调用。
- **兼容与恢复**。检查旧数据、已有操作记录、路径和数据库版本，确认取消、重复请求和崩溃后的权威位置与文件状态。
