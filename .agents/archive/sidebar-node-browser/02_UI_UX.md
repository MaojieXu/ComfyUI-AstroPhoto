# 侧栏与节点浏览 · 交互规格

**v0.5 · PRD v0.14 交互对账**。沿用现有 Vue 布局和交互载体，目标规则见下方补充。真实宿主复验按测试计划进行。

| 区域 | 起点、操作及返回 | 状态与反馈 |
| --- | --- | --- |
| AstroPhoto Sidebar（FR-01、05） | 在宿主打开唯一入口。默认 Assets。有同注册实例暂存的设备或光路草稿时恢复到 Settings → Equipment & Optics。在三标签间点击切换，用方向键/Home/End 移焦、Enter/空格激活。 | 当前面板以选中状态与 `aria-selected` 标识，其他面板隐藏；设备编辑可阻止离开。 |
| Assets（FR-05） | 默认显示 Projects，可切换 All Assets，也可从素材页进入 Settings → Storage。 | 初始加载、空态和业务错误由素材库界面呈现；仅浏览不提交素材写入。 |
| Nodes（FR-02、04） | 首访加载目录，使用搜索框及清除键、复选分类、原顺序或名称排序，侧栏顶栏可刷新。收藏在普通目录上方，使用相同搜索和分类条件。 | 分开显示加载、失败和重试、真实空目录、无匹配、空收藏。切换主标签保留挂载会话的搜索、筛选和展开；非空搜索自动展开匹配路径且可手动收起。 |
| Settings（FR-05） | 模块卡片进入对应页，通过返回回到卡片。已接线的是 Storage、Environment、Software、Equipment & Optics、System。 | 设备能力未就绪时显示 loading、原因或可重试错误。System 显示版本、API 和能力。Knowledge、Memory 与 Agent 是说明入口。 |

- **详情（FR-04、D-04）**。分类从浏览树查看。选择节点显示标题、ID、说明或缺说明提示、已注册文本及输入输出名称和类型。依赖文字和帮助不可用是固定说明。可用键盘进入详情和触发添加，目标焦点规则见下方，当前详情返回缺显式焦点恢复。
- **预览（FR-04）**。鼠标悬停显示含微缩节点、说明和端口的只读浮层。浮层对辅助技术隐藏。离开行、开始拖拽、选详情或切标签时关闭，滚出可见区隐藏。空间不足时尝试更换侧边并约束到窗口，真实窄宽和缩放待验。
- **当前收藏实现（FR-02）**。节点行有 `aria-pressed`，目前合并顶层和类别路径状态。D-14 下方规则替代该行为。失效引用仍留在宿主设置。
- **添加（FR-03）**。节点行打开详情，“添加到画布”在活动画布中心创建，也可直接拖行到画布背景。创建成功和失败有反馈。当前列表行无独立加号，撤销、重做及保存由宿主管理。

宿主提供主题；Vue I18n 将宿主 `zh` 变体归为中文，其余回退英文。键盘、主题、窄宽、边缘和历史 React 状态需按适用版本核对。 [测试计划](05_TEST_PLAN.md) · [历史侧栏](../../../docs/react-sidebar.md) · [历史节点树](../../archive/sidebar-node-tree.md) · [原生标签](../../archive/native-sidebar-tabs.md)

D-05 确认节点与画布跟随 ComfyUI 原生交互。切图后的目标、有效落点、取消和撤销均按同版宿主节点库核对。原生入口和侧栏入口的差异是复验项。 [PRD](01_PRD.md)

D-07、D-08、D-10 确认既有交互。失效收藏隐藏、恢复后重新显示；同一页面内保留浏览条件，重建后重置；鼠标悬停预览，键盘和触屏走详情。D-09 的错误反馈以所接入宿主路径为准。D-11 的入口不可用时，引导用户经原生节点库完成受影响动作。 [PRD](01_PRD.md)

## PRD v0.15 的目标状态

- **标签首页（D-19）。** 点击当前标签或从其他标签切回，节点显示目录，素材显示「项目」，设置显示模块列表。节点详情中的返回按钮继续恢复原目录行焦点。顶部标签激活时焦点留在标签；取消丢弃草稿可继续编辑。素材导入页「打开存储设置」直接显示存储详情。

- **焦点。** 打开详情将焦点移到可访问的详情返回控件。返回后聚焦原目录行或收藏行，行已消失则聚焦搜索输入。搜索选项弹层按 Escape 收起并返回触发按钮；仅鼠标打开的悬停预览按 Escape 收起，当前焦点不在该行时保持原焦点，且鼠标重新进入后才可再弹出。宿主其他 Escape 交互保持自身处理。
- **既有中英文反馈键。** `nodes.noBookmarks` 用于 Ready 的空收藏，`errors.bookmark` 用于保存失败，`nodes.created` 仅在创建成功后提示使用宿主保存，`nodes.noDescription` 用于没有说明。`states.loading`、`actions.retry` 与共用 `errors.*` 覆盖目录加载和失败。新增行为仍需接入反馈键。
- **设置状态。** 公共模块状态来自既有能力及请求结果。未配置、执行依赖错误由提供真实状态的 Bundle 页面呈现，例如 Siril 现有详情；公共卡片显示模块入口是否可用。

- **刷新与可操作范围（D-12/13）。** 刷新开始撤下旧目录、预览和详情添加入口；失败区域仅显示错误与重试。新目录就绪后沿用当前查询与有效筛选。树、详情、收藏解析和自有拖放共享同一可发现范围。
- **收藏（D-14）。** 目录收藏按钮的选中态只表示顶层引用。收藏树里的移除操作指向所在条目的完整路径；同 ID 在其他路径的条目独立。保存失败有提示，按钮状态以宿主真实回读为准。
- **默认视图与草稿（D-15/16）。** Assets 保持默认落点，接入摄影素材库的 Projects 和 All Assets（D-18）。有可恢复草稿时优先回 Settings → Equipment & Optics。在应用内离开 dirty 编辑会提示，取消或保存失败保留输入。浏览器刷新或注册销毁会结束会话内草稿。
- **宿主接入（D-17）。** 以已验证的宿主组合提供完整添加交互。某个动作无法安全接入时，提示使用宿主原生节点库完成对应操作。
