## 当前结论 · 摄影素材库 v0.7

**PARTIAL · 2026-11-21 · 保持活动。** 现行已确认需求为 [PRD v0.7](01_PRD.md#astrophoto-摄影素材库-prd-v07) 与 [UI/UX v1.0](AstroPhoto_Assets_UI_UX_v1.0.md)。旧合并前的 Close 上文留作历史。

| 验收面 | 结论 |
| --- | --- |
| 登记、存储和项目 | 真实宿主验证 Reference、浏览器 File Copy、跨 Tab 虚拟落点。HTTP 覆盖重复登记、预检失效、注销、受管删除和关系保护。终态文件重试使用原冻结清单选出仍可重试的条目，不重复已成功的条目。2.5 GiB 合成视频通过流式 Copy 和 SHA-256 比对，1,701 项清单预检通过。超大目录完整浏览器选择与上传的压力仍待验。 |
| 校准库与科学属性 | HTTP 断言 Flat 资格、已知条件冲突、需要确认的关联及独立科学状态。浏览器可一次提交多个用途，并在参数差异后确认。Agent 可经 MCP 提议关联，界面尚缺独立的 Agent 推荐入口。 |
| Canvas 与正式结果 | 真实宿主 Asset 和 Collection Source、Siril、队列历史、旧宿主与 Nodes 2.0 Inspector 主动收录有证据。其他影像格式由下游节点消费。 |
| Agent 工具 | FastMCP 4.2 进程内客户端、真实 stdio 与真实 aiohttp/SQLite 联合证明发现、CRUD、导入审批及脱敏拒绝。附加的真实 ComfyUI stdio 审批测试因自动命令审查拒绝携带临时令牌启动隔离宿主而未完成。 |
| UI 可用性 | Chromium 组件和真宿主分别验证关键路径。独立覆盖大文件选择窗口、窄视图高倍缩放、读屏及完整错误恢复仍有缺口。 |

受控 Workspace 移动继续使用 Settings 的存储流程。单文件移动／覆盖与后台任务中对所有物理引用的完整识别仍有边界。保持活动直到所需产品行为和验证满足，并沿用 [测试报告](06_TEST_REPORT.md#2026-11-21--摄影素材库-v07-当前批次) 区分实测和计划。
