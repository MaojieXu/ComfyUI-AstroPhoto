# ComfyUI 扩展底座与绘图节点 · 交互规格

**版本** v0.4 · 2026-11-21 · 现行界面基线与评审差异

## 宿主入口与主界面

用户在 ComfyUI 节点目录添加 Vue Basic（`vue-basic`），或者打开含该节点的旧工作流。节点内部从上到下显示本地化标题、画笔及清空按钮、颜色按钮、笔刷大小滑杆、白底画板；恢复报错时在画板下方显示反馈。工作流保存、分享、画布模式切换、队列及结果均使用宿主界面。状态端点供诊断，无本专题单独配置页。关联 FR-01～04。

| 部分 | 当前显示和交互 | 对照点 |
| --- | --- | --- |
| 工具与画板 | 画笔默认选中。黑色、5px 为默认值，滑杆 1～50px；七色从黑、红、蓝、绿、黄、洋红、青中选择。绘图实例为 300×300 像素，白底。鼠标和触摸可画；缩小节点时画板受容器约束。 | 笔画结束后核对改变后的 PNG；选中态除视觉样式外有按钮 `aria-pressed`。滑杆有可见说明，当前模板未将说明关联到 input，屏幕阅读器名称为检查项。 |
| 清空与继续编辑 | 清空立即重新填白并保存当前 Widget 值，无二次确认。下一笔可继续绘制。 | 验证清空后重开。宿主图级撤销、Widget 值回放和笔画级撤销分别判断；当前没有专属笔画历史界面。真实宿主以完成一笔、清空、撤销与重做的像素序列评审，同时核对另一实例不会被改动。 |
| 语言和模式 | 从宿主当前语言读取，中英文显示实际词条。经典画布和 Nodes 2.0 复用同一 Widget。画板白色属于像素内容，两种主题下标题、滑杆和错误提示需可读。 | 主控件支持键盘触达，使用指针或触摸绘画。宿主模式、缩放和窄卡片复验要记录焦点、可读性与目标点与实际 PNG 落点的偏差。触摸中断后也应核对下一次起笔和保存状态，当前只监听 touchend。 |

## 状态与反馈

| 状态 | 触发与当前可见呈现 | 恢复、限制及验收 |
| --- | --- | --- |
| 新建或旧空值 | 白底可用，没有专属空态提示。 | 可以落笔；旧空记录无原笔画可恢复。 |
| 打开内嵌 PNG 的工作流 | 图片异步解码，当前无加载提示或交互锁。 | 正常完成后显示保存的像素；用户在完成前已经开始画或清空时，旧恢复结果失效。旧像素若尚未绘入，新笔画可能从白板开始。Q-03 决定是否接受。 |
| 无效保存内容 | PNG 格式不符、解码失败或尺寸不符显示本地化 `role=alert`。 | 完成有效编辑后清除提示。英文与中文使用词条，当前英文为 “Unable to restore the saved drawing. Check the image data in the workflow.”。 |
| 保存与分享 | 使用宿主保存，画板快照随工作流。笔刷颜色、笔刷大小和选中工具没有作为单独的恢复字段。 | 没有专属脱敏导出；是否只提供白板副本操作说明待 Q-02 确认。 |
| 上传及队列 | Widget 不显示专属进度或后端成功提示，由宿主队列与节点输出显示。 | 临时 PNG 上传和正式 IMAGE 分别判断；返回空引用或缺少下游结果都不能标为成功。发行说明按 Q-01 决定。 |

## 评审载体与验收方法

当前可直接挂载真实 Vue Widget 评审，浏览器组件夹具使用真实 Canvas 与宿主替身；真实宿主对照读取同一旧工作流并在两种模式拍摄对应画布。已留存采样截图位于本机 `.artifact/frontend-migration/classic/workflow.png` 和 `.artifact/frontend-migration/nodes-2/workflow.png`，用于比较版本，当前构件需另取证。本轮是现状规格与待决交互评审，确认 Q-02/Q-03 前，导出和恢复体验仍为未定项。
