## 主界面 · ComfyUI 画布

| 入口与任务 | 状态及实际操作 | 用户结果 |
| --- | --- | --- |
| FR-02、FR-04 · 添加 AstroPhoto Load Image | 选择已登记 FITS，或在同一个 Widget 输入 ComfyUI 服务器上的绝对路径。列表加载时显示等待，可刷新，错误有提示。未出现在列表的已保存 ID 保留为不可用选项；重名条目附 ID 前缀。 | 工作流保存的是单个 ID 或路径。刷新列表不重绑同名文件。当前 Assets 页为占位，所以已有登记可选，向当前用户提供的直接入口是服务器路径。 |
| FR-02、FR-04 · 添加 AstroPhoto Image Path | 使用宿主原生文本 Widget，原样提供 `IMAGE_PATH`。把任一来源接入 Siril · AutoStretch。 | 正式队列在消费时校验路径与内容。旧 `ASTRO_FRAME` 或 STRING 连线需手工迁接。 |
| FR-02 · 编辑 AutoStretch | 原生参数默认 −2.8 σ、0.25、联动开启。未连接时提示补输入；连接但无法识别候选来源时提示执行上游。来源或参数变化进入渲染态。 | 候选只显示当前请求键；参数有效变化、手动刷新、可匹配的正式执行结果或 PNG 配置变化触发更新。单色候选返回后关闭 Inspector 联动控件，并禁用原生联动 Widget。 |
| FR-02、FR-05 · 预览工具栏 | 预览默认展开，可折叠、打开比较、刷新、重置。未配置或处理失败时显示错误，有效输入的处理前图可能仍可查看。 | 展开、比较、平移、缩放本身不启动新任务；移除节点中止客户端任务并释放图像。可对现有来源手动刷新。 |
| FR-03 · 提交正式结果 | 使用 ComfyUI 原生 Queue，运行和错误沿用宿主状态；候选预览无需提交队列。 | 成功时输出 `IMAGE_PATH`；参数与来源仍匹配时预览标注正式结果。回执与文件位于活动默认 Workspace，当前 Assets 页面没有正式结果台账。 |

画布在 `read_only` 或 `selectOnly` 时阻止来源和 Inspector 修改写回。来源控件默认仍可聚焦；数字控件可有临时输入显示，焦点离开清除草稿。该闸门证据是工作流值保护，控件禁用视觉和宿主焦点行为仍需验证。

## 子界面与恢复

候选在比较界面应能区分等待、前图可用、后图失败、候选就绪和已登记正式结果。正式结果与当前源或参数不再匹配时，沿用当前候选反馈。队列因默认工作区不可写失败时，保留节点参数及资产选择。用户恢复原工作区或显式选择新默认后可重新 Queue；工作区迁移后，固定旧路径的工作流可重新选同一资产或重新执行上游。错误提示、工作区切换后的回执与路径恢复需按 CASE-11/14 在两种画布复验。 [PRD](01_PRD.md) · [测试计划](05_TEST_PLAN.md)

**图像比较 · FR-02、FR-05。** 从预览工具栏打开原生 `dialog`，支持并排、滑动分割和单图。两侧同步平移/缩放，100% 对应 PNG 像素。只有两图可用且后端返回对齐时才能分割；不对齐可退回并排或单图，只有前图时仍能查看。可用关闭按钮或宿主 Escape 事件退出；分隔条可调图像/参数的区划。右侧参数修改同步回节点，重置采用节点默认值；单色联动禁用。分割滑块提供键盘处理和 ARIA 数值，按钮具有命名；既有双画布验证覆盖明暗主题和比较模式；窄画布裁切、真实 Tab 顺序和焦点恢复仍待验证。

**Settings → Software → Siril · FR-01。** 列表卡片展示用途、验证结果和独立启用开关，详情按服务器 OS 提供指引。检测列出候选路径、来源、版本和状态，仅合格项可用 Select 回填。手工输入绝对路径或提交已保存路径以重验。提交或检测期间禁用相关操作并显示忙碌状态；失败显示错误及可得的检测版本。成功展示验证路径、版本与时间，清除按钮移除当前配置；禁用开关保留已验证配置。退出页面中止客户端等待。服务端提交取消未实现为可见动作，产品规则见 Q-05。

**Settings → Environment · FR-05。** 用户选择并保存 PNG 最长边，可在 512/1024/2048/4096 与原尺寸间切换。首次载入、保存时、保存成功、失败和修订冲突有独立反馈，冲突后先刷新再提交。当前画布显示默认宽 480、最高 320 CSS 像素，节点空间不足时缩小并保持纵横比；此面板没有画布宽高字段。当前结果共用同一对预览图。

## 宿主复用与证据

前端由 `registerFitsSource`、`registerAutoStretch` 通过 `registerExtension` 和 `addDOMWidget` 挂载，双语文案随 Vue i18n 和宿主主题；状态包含可读文本。共享 `NodePreview`、`Inspector` 承担显示与比较，Siril 组件提供参数区和候选状态。历史设计参考宿主 1.59.1 的 ImagePreview 与 VideoCompareSlider，现阶段实际设备、浏览器和可访问性以 CASE-02、04、05、06、08、09、13 为准。 [来源 Widget](../../../frontend/src/host/fitsSource.tsx) · [AutoStretch 界面](../../../extension/siril/frontend/AutoStretch.tsx) · [比较窗口](../../../frontend/src/features/nodes/preview/Inspector.tsx) · [测试计划](05_TEST_PLAN.md)
