# MCP 诊断与设备只读查询 · 交互规格

**版本** v0.4 · 2026-11-21 · PH-02 宿主界面 N/A

本专题由第三方 MCP 客户端管理进程和工具界面。AstroPhoto 没有新增 UI、独立授权面板或专用原型。下面记录客户端可以呈现的状态和恢复路径。外观、语言、键盘和焦点由客户端负责。错误以协议中的工具错误和现有英文消息呈现。

| 场景 | 用户动作及反馈 | 下一步 |
| --- | --- | --- |
| FR-01/04 连接 | 客户端启动独立进程并 initialize。合法配置出现 version 和 connection_status；非法地址在启动时给出 CLI 配置错误。 | 修正进程配置后重启客户端连接。 |
| FR-01/04 诊断 | version 显示 MCP 安装版本。connection_status 在宿主可达时给出注册状态；未找到节点可正常返回未注册。断连、HTTP 或无效 JSON 是调用失败。 | 根据错误检查 URL、宿主状态或扩展加载；可再次发起诊断。 |
| FR-02/05 权限 | 合规本机配置可显示六项额外查询。枚举成功后仍可能因宿主未启用可信部署或 token 不匹配而出现 403 工具错误。 | 检查可信部署和两端进程配置；令牌更改后按 Q-01 的候选流程复验。 |
| FR-05 替换与撤销 | 宿主重启载入替换值后，旧 MCP 会话仍可能列工具，后续读请求被拒。以新值重启客户端进程后可恢复查询。 | 先通过 `connection_status` 检查宿主已恢复，再分别以旧、新会话检查权限。接入文档只记录结果，不写凭据值。 |
| FR-02 读取 | 查询返回列表、详情或历史；空列表是正常结果，空游标表示末页。无记录、无权、超时和坏响应走错误反馈。 | 分页时使用返回游标；历史列表为空时保留当前设备组合查询。 |
| FR-03 安装 | 用隔离安装和本地 version/握手确认独立构件；公开渠道结果单独记录。 | 分别诊断安装失败和宿主连接失败。 |
