 新发现（按严重度）

 F-6｜P3｜既有、环境相关：Siril 的 msys2 提示被当作执行失败
 - 位置：extension/siril/processing.py:15（FAILED_LINE）、:43（命中即抛 SIRIL_RUN_FAILED）；基线
   4c0cf4d:astrophoto/siril/processing.py:20,45 相同，非本次迁移或修复引入。
 - 触发：ComfyUI 进程环境带 MSYSTEM/MSYS（从 Git Bash/MSYS2 启动），Siril 每次输出 log: Error: msys2 environment detected. Siril Python
   support cannot be correctly initialized.。
 - 影响：候选预览与正式处理都走 process()，会以 SIRIL_RUN_FAILED 失败，尽管 result.fit 已正确生成（脚本日志同时含 Script execution
   finished successfully）。
 - 证据：MSYSTEM=MINGW64 下 tests/backend/test_siril.py -k real_cli 2 项失败并留下 result.fit；清除该变量后同一命令 2 项通过。修复建议：
   在 run_cli 的 env 中去掉 MSYSTEM/MSYS，或把该条已知提示从 FAILED_LINE 中豁免，并补一条含此日志行的替身用例。
