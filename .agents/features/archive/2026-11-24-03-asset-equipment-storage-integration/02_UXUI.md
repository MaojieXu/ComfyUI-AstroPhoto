# 素材导入交互

## 类型驱动导入（现行前端，DEV-040）

统一“导入素材”：先选子帧组、视频、Master Frame 或图像结果；子帧组选择一个文件夹，其余各选一个文件，取消返回类型选择，选后可重新选择。Master Frame 和图像结果入口独立但共用底层精简图像结果结构，外部生成文件可导入。导入页不选项目。

配置页按类型展示：子帧组显示名称、类型、备注、设备组合、实际滤镜、可选拍摄参数和校准状态，文件默认显示数量并可展开；Light/Flat 支持可选校准主帧，展示差异与未知并按最终规则请求确认。视频、Master Frame 和图像结果显示名称、可选设备组合、滤镜和备注；视频不绑定校准场。三类素材详情均可查看、修改和解除设备组合绑定。名称默认文件/文件夹名，未知参数可留空；具体滤镜仅可从已选组合选择，组合没有滤镜时可选择无；未选组合不提供具体滤镜选择，未知不自动变为无。子帧拍摄参数可折叠。

主要按钮为“导入”，系统先预检；需要用户决定的情况显式提示。导入成功而绑定失败须分别提示并提供绑定重试，不重复导入；绑定不等同于已校准。两种存储模式保持一致的配置体验，保留模式必要能力及选择器不可用回退。视觉布局和具体文案待实现验证，匹配规则见 PRD Q-04、Q-07、Q-10。

## 项目树及素材选择（DEV-094、095、098、105）

子帧组使用线条箭头标记可展开行，展开后在同一项目树中缩进列出原文件名，组行显示已读取的总数。长文件名省略但可查看全名。单帧路径、大小和可用状态以行内只读信息显示。滚动接近末尾加载后续页，保留手动加载入口，失败提示与重试显示在该组内。右方向键展开组，左方向键可返回组行或收起该组。

项目工具栏仅保留搜索。右键空白处创建项目；右键项目或文件夹可创建文件夹及添加已有素材，右键素材时上述操作作用于其父文件夹。空项目显示右键创建提示，键盘可通过上下文菜单键或 Shift+F10 打开菜单，Esc 关闭。项目和节点行不显示省略号按钮。

新建项目或文件夹与重命名均使用行内输入，Enter 或失焦保存有效名称，Esc 取消；空白、非法或重复名称退出临时输入且不更改原记录，服务错误保留输入供重试。移动目标排除自身及后代，移除引用时说明保留素材和源文件。添加素材选择器显示目标项目及逻辑路径，复用素材库搜索与筛选，四类素材可跨筛选多选；当前项目已引用项不可选，批量提交失败保留选择，每次最多 100 项。真实窄侧栏、触屏和输入法交互待验。
