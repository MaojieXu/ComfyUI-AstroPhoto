# 本机直连与业务规则技术设计

状态：已归档。chat1 于 2026-11-25T07:45:30-06:00 补记，正式验收范围见 [测试报告](06_TEST_REPORT.md)。FR-02、FR-03。已实现的本机调用和目标发现以源码与 DEV 日志为准。

- MCP 保留 stdio，并使用扩展公开 HTTP API；服务端维持受信本机直连边界。业务凭据、工具注册与审批脱钩；`Authorization` 不再作为 Agent 身份判据。
- 显式地址优先。Desktop 端口锁须通过 PID 与监听端口核对，再经 HTTP 验证。一次调用固定目标。自动模式将导入任务的地址和存储实例 ID 写入 MCP 自己的 SQLite，重启后按实例 ID 核对。原地址失效时，仅在唯一发现的实例 ID 匹配时恢复查询。
- 素材注销在一个写事务中清理项目引用和校准绑定，再清理目录登记；文件保留。设备删除在一个事务中解除当前引用并保留快照。项目删除只移除树和引用；存储位置移除和受管文件删除是独立操作。
- 写入只更新已提供字段，不以过期版本拒绝；对象不存在明确报错。数据约束、事务与路径所有权识别仍是实现正确结果所需机制，不作为人工审批门槛。
- 涉及 MCP 客户端、HTTP 路由、SQLite 服务、前端调用及文档；各增量须以隔离数据库与临时目录验证。真实 stdio、双物理盘、真实界面操作和 Computer Use 排除。

产品 Skill 由 MCP wheel 和 sdist 分发。FastMCP 4.2 从包内目录提供资源与 Skills 扩展；安装命令通过 FastMCP 的 Skill 文件接口写入用户指定的父目录。安装已有同名 Skill 时报告错误。后续客户端验收需分别检查原生发现或磁盘加载，以及连接 MCP 后实际使用业务工具。

## 分类披露技术契约（FR-04）

FastMCP 4.2.0 的 CatalogTransform 安装于 local_provider，避免服务级 transform 使 SkillsExtension 隐藏 Skill；入口目录通过 get_tool_catalog 取得经过可见性过滤的真实工具，使用官方 MCP 序列化导出 Schema。业务工具按名称前缀和状态名称映射到六类，真实注册集决定可用类别。直接工具查找不被拦截。代理经 ctx.fastmcp.call_tool 触发正常中间件；TargetMiddleware 跳过外层发现和代理入口，内部按实际业务名称绑定目标和保存/恢复导入来源。服务 instructions 为英文；客户端是否注入未保证。
