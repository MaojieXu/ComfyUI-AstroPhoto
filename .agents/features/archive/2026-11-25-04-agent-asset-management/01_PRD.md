# Agent 素材与设备管理交付 PRD

状态：已归档。2026-11-24 需求草案为历史基线，chat1 于 2026-11-25T07:45:30-06:00 记录当前验收见 [正式报告](06_TEST_REPORT.md) 与 [关闭记录](07_CLOSE.md)。

## 目标

将现有 AstroPhoto Extension 的素材管理相关能力打包，围绕真实 Agent 开展最终测试与联调。形成面向扩展业务的 Skill，使 Agent 能理解和操作素材管理、设备管理及项目管理等相关能力。用户希望以后能够通过 FastMCP 将该 Skill 安装到本地。

## 已确认范围

- 整理素材、设备、设备组合及项目管理的现有能力和打包交付范围。
- 开展真实 Agent 与扩展、MCP 的联调和最终测试，记录可复现的结果与未覆盖范围。
- 使用 OpenCode Go Plan 提供模型访问，选择非 OpenCode 的 Agent 客户端开展真实联调和可观测性验证；Pi 是候选客户端，最终选型及兼容性待验证。
- 在真实 Agent 联调中提供调用链和业务结果的可观测性，支持定位执行过程和核对实际结果。
- 交付支持上述管理工作的业务 Skill，并探索通过 FastMCP 安装至本地的方式。
- Agent 经 MCP 直连本机 AstroPhoto 业务能力，不要求配置认证凭据、聊天审批或业务保护。
- 保留手动配置 ComfyUI HTTP 地址的能力，并在未配置时自动发现可用的本机实例。
- 延续仓库约束。外部 MCP 仅通过 ComfyUI 和扩展公开 API 访问业务能力，不直接访问宿主内部实现或业务数据库。保护用户文件及 FITS 数据精度与元数据。

## 真实 Agent 联调可观测性

**FR-01 — 调用链与业务结果可观测**

- 对约定的真实 Agent 联调场景，使用选定的非 OpenCode Agent 客户端和 Go Plan 模型；通过客户端提供的事件或会话记录，查看可获得的 Skill 激活、工具调用及其结果。
- 在 AstroPhoto 可观测范围内，记录 MCP 工具调用、扩展公开 API 和后台任务的可获得执行信息，包括结果、耗时及失败信息，以支持定位问题。
- 将同一次任务中可关联的 Agent、MCP 和扩展侧证据进行关联；具体关联方式和自动透传能力需在选定客户端版本与实际联调环境中验证。不可获得、丢失或无法关联的环节应明确标示，不能推断为已执行或成功。
- 对产生业务变更的操作，能够核对关键业务状态与操作结果，例如素材导入数量、失败项、设备关联和项目素材关联。实际结果通过扩展公开入口回读；未能确认的结果应明确标示。
- 联调记录应足以辅助复现和定位问题，并遵守现有项目的用户文件和业务数据保护约束；记录可能包含对话、工具参数和文件路径，具体采集范围及处理方式待确认。

**验收条件**

- AC-01：对约定的成功场景，使用选定的非 OpenCode Agent 客户端和 Go Plan 完成真实 Agent 任务；能够查看客户端实际提供的 Skill 激活及工具事件、服务侧可获得的调用顺序和执行结果，并通过公开入口核对最终业务状态。
- AC-02：对约定的失败或部分成功场景，能够识别失败步骤、可获得的错误信息及已确认的业务结果；缺失或无法确认的记录有明确标示。
- AC-03：联调证据能够将可关联的 Agent 会话、MCP 调用和扩展侧记录对应到同一次任务；注明实际客户端、版本、模型、环境、测试数据，以及未覆盖、丢失或不可关联的环节。
- AC-04：对事件订阅中断或信息缺失的情况，联调记录注明证据缺口；客户端可提供会话记录时用于核对，无法补齐的部分保留为未验证。

观测边界：Go Plan 提供模型访问；Agent 侧观测依赖所选客户端版本实际提供的事件或会话记录。MCP 服务无法独立观测外部 Agent 的内部过程，也不能由工具调用推断 Skill 已激活。模型内部隐含推理的完整观测不属于本次已确认范围。

事件字段、订阅可靠性、会话记录可用性、关联方式，以及记录的具体内容、展示与保存方式、保留期限和是否需要汇总指标，尚待验证或后续设计确认；本需求不预设特定技术方案。

## 本机直连与操作要求

**FR-02 — 无认证、无业务保护的本机直连**

- Agent 通过 MCP 调用本机扩展的公开 API，素材、设备、设备组合及项目操作不要求配置业务 token、认证或聊天审批。
- 不要求保留引用保护、版本冲突检查、删除影响预览等业务保护门槛；具体删除及关联数据的结果需在设计前明确，不能假定删除物理文件。
- 范围为本机直连、单用户使用；不因本需求自动开放局域网或公网。其他本地进程可能访问同样的接口，此限制已纳入需求理解。

**已确认的删除结果**

- 删除设备时，解除设备组合、校准主帧等现有记录对该设备的当前关联；保留已有素材的历史设备快照及其中记录的拍摄设备信息。关联对象本身不因此删除。
- 删除设备组合后，该组合不再可供新素材选择；已有素材继续保留当时使用的设备信息。底层是否保留已删除组合记录由后续技术设计决定。
- 素材库注销移除素材登记及各项目中指向该素材的节点，保留项目、其他素材及磁盘物理文件；注销已绑定的校准主帧时自动解除相关绑定，保留其他素材及绑定。
- Storage 删除移除指定的 AstroPhoto 受管文件，包括位于 `.astrophoto` 之外的外置工作区中由 AstroPhoto 管理的文件；其他外部文件保留。删除范围以文件是否由 AstroPhoto 管理为依据，不能仅凭是否位于 `.astrophoto` 内判断。
- 删除受管文件和移除存储位置是独立操作；移除位置时该位置内受管文件的处理由该操作明确指定，不能默认全部删除。
- 删除项目或文件夹时移除其结构与下属项目引用，保留素材库记录和磁盘文件。
- 并发修改时，同一字段以最后提交的值为准；未提交字段保持不变。更新时目标已不存在则返回对象不存在，不重建或伪报成功；删除时目标已不存在则明确报告已不存在。

**验收条件**

- AC-05：在约定的本机环境中，不配置上述业务 token 或审批开关，MCP 可发现并执行约定的素材、设备、设备组合和项目操作。
- AC-06：约定操作不因聊天审批、引用保护、版本冲突检查或删除影响预览而被要求额外确认或阻断；实际结果可通过公开入口回读。
- AC-11：删除被引用设备后，相关对象仍可读取，当前设备关联解除，已有素材的设备快照保留。
- AC-12：删除设备组合后，新素材不能选择该组合，已有素材仍能读取其历史设备信息。
- AC-13：素材库注销后素材登记不再可查，原物理文件仍存在；Storage 删除后，指定的 AstroPhoto 受管文件被移除，包括外置工作区中的受管文件，其他外部文件仍存在。
- AC-14：注销被多个项目引用的素材或被绑定的主帧后，对应项目引用或校准绑定自动移除，其他对象和文件保留。
- AC-15：删除项目或文件夹后，仅其结构及下属引用消失，素材库记录和物理文件保留。
- AC-16：并发修改以字段为单位后提交者生效；目标已不存在时更新报告不存在，删除明确报告已不存在。
- AC-17：移除存储位置不等同于删除其全部受管文件；其处理按该操作明确指定。

## ComfyUI 地址配置与自动发现

**FR-03 — 连接本机 ComfyUI 实例**

- 保留通过 `--comfy-url` 和 `COMFYUI_URL` 手动配置 HTTP 地址，命令行参数优先。显式配置的地址始终优先；不可达或无 AstroPhoto 扩展时报告问题，不自动切换到其他实例。
- 未显式配置时，优先尝试发现运行中的 ComfyUI Desktop；未发现 Desktop 实例时，尝试常见本机地址 `127.0.0.1:8188` 和 `127.0.0.1:8000`。验证候选实例可访问且已加载 AstroPhoto 扩展后使用。
- 发现多个可用实例时，向用户提供候选地址及可获得的实例信息，让用户指定目标，不按端口顺序猜测。未发现可用实例时，提示启动 ComfyUI 或手动指定地址；常见端口探测不保证发现任意自定义端口。
- 显示当前连接地址、手动配置或自动发现的来源、ComfyUI 连接状态及 AstroPhoto 扩展状态。
- 支持 MCP 先于 ComfyUI 启动、连接中断和 Desktop 重启导致端口变化后的重新发现。进行中的业务操作保持原目标；连接失败时报告失败，不在操作中切换实例。重新发现的目标仅供后续操作使用，多实例仍须由用户指定。

**验收条件**

- AC-07：手动指定地址时，连接状态显示该地址及手动来源；地址不可达或扩展未加载时报告相应问题，不切换到其他可用实例。
- AC-08：未手动配置、仅有一个可发现且已加载扩展的目标 Desktop 实例时，MCP 自动连接并报告地址与发现来源；Desktop 未发现时能按上述常见地址规则尝试。
- AC-09：多个可用实例时展示候选并等待用户指定；没有可用实例时给出启动或手动配置提示，不把不可用实例报告为已连接。
- AC-10：MCP 先启动、宿主稍后启动或端口在重启后变化时，可重新发现目标；进行中操作连接失败时报告失败，后续操作才使用重新发现的目标。

Desktop 端口锁、进程匹配、不同操作系统和版本的发现能力及验证方式须在设计和实际环境中核实；不承诺覆盖所有安装方式。

## MCP 工具逐步披露（FR-04）

- MCP 在连接时提供英文服务说明；客户端是否将说明提供给 Agent 取决于客户端。
- 工具初始列表仅展示类别发现、类别工具发现和调用入口；按 connection、equipment、equipment_groups、library、projects、storage 展开实际可用的业务工具定义。未实现的画布工具不展示。
- 保持现有业务工具的名称、参数、结果和错误契约；保留按已知名称直接调用。分类披露不构成授权边界。
- 发现类别不要求宿主就绪；业务调用仍按现有规则绑定实例，导入任务来源和恢复继续有效。

验收条件：六类完整且不重复；自动和手动配置只披露实际注册工具；入口返回说明、输入 Schema 和注解；代理执行、错误及自动发现的导入任务来源与直接调用一致；Skill 资源和 Skills 扩展继续可发现。
