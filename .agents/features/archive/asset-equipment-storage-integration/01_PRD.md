# 素材、设备与多磁盘闭环 PRD

状态：已确认的数据模型与导入目标，实施中；部分匹配和操作细节仍需确定。创建日期：2026-11-22。

## 目标与边界

本 Feature 面向使用 AstroPhoto 管理天文摄影素材的用户，贯通数据库中素材、设备、设备组合（设备 pair）及 workspace 多磁盘管理，以及校准场绑定、设备组合绑定、前端展示和 MCP 导入的完整链路。重点包括可复现的 FITS 测试数据生成、MCP 导入优化和真实联调。

用户已确认新建 Feature，并继承现行规则、引用[已归档联调 Feature](../equipment-image-data-integration/00_FEATURE_INDEX.md)及其证据；不是重新宣称历史验收通过。业务行为沿用[历史 PRD](../equipment-image-data-integration/01_PRD.md)和 [MCP 契约](../../../../docs/mcp.md)，除非本 Feature 后续经用户确认予以修改。跨层实现细节留待 TECH；当前工作为需求澄清与 PRD 更新。

## 范围与功能要求

以下目标由用户确认；具体产品行为、边界和可执行验收步骤在相关问题解决后补充。历史已有能力是基线，不代表本轮已完成验证。

**前端通用设计要求：** 本 Feature 的界面适配 ComfyUI 窄侧栏，控制面板及控件的宽度、高度和间距，字号偏小且清晰易读，避免不必要的大面积空白；下拉框、展开选项、字体与间距应符合 ComfyUI 的紧凑风格，优先复用适用的宿主组件与主题。中英文、长文案和窄窗口应可正常展示和操作，不得以压缩内容为代价遮挡必要信息。

**前端实现后检查：** 仅在用户明确要求时使用 Computer Use 检查界面，记录实际验证范围。界面继续遵循紧凑、清晰、可操作的要求。可展开分区统一使用现有线条箭头折叠控件的样式和交互，避免浏览器默认的实心三角标记。

### FR-01 数据与设备关联

设备组合详情只保留“当前配置”模块；相机、主光学、附件、滤镜及其他设备在该模块内展示，不再单列组件详情、可用滤镜和其他设备模块。编辑、归档及删除操作保持可用。

#### 素材结构（最终模型）

v0.0.1 使用最终模型作为集合、项目和校准的唯一入口。旧关系记录作为测试数据清理，无须转换，也不显示旧入口。实际文件继续由存储服务管理。

素材管理分为素材库和项目。素材库包含子帧组、视频、主帧和图像结果。子帧组可追加多个文件夹并包含多个子帧文件；主帧和图像结果各为单个图像文件。主帧按用途区分图像主帧和暗场、平场、偏置场、平场暗场及未知；校准用途记录参数并支持子帧组绑定，见 FR-02。素材文件支持仅登记原位置或复制至工作区，不读取文件内容或元数据作为 Agent 的识别依据；Agent 依据名称和用户说明，未知时保持未知并询问用户。

复制模式下默认工作区为 `storage/Local`，受管素材按 `objects/{subframes|videos|masters|images}/素材名称/原始文件名` 保存，不在长期目录或文件名中添加 UUID；多工作区同组使用相同素材名称。冲突、非法名称或路径过长时明确报告，不覆盖文件或静默改名。追加子帧保留原始文件名，重名时拒绝覆盖。复制素材改名须同步改目录和已登记路径，并可在失败或中断后恢复；引用模式保持原路径，改名不移动原件。项目是逻辑引用，不改变物理位置。现有数据为测试数据，无须长期旧目录兼容，重建时保留工作区外源素材。

子帧组记录名称、帧类型、可选曝光、ISO、Gain、Offset、Binning、相机读出模式、温度和备注；温度保存原值。帧类型为 light、dark、flat、bias、dark_flat、unknown。校准状态为 calibrated、uncalibrated、unknown，默认 unknown；绑定校准主帧不等于已执行校准。同一子帧组内曝光、ISO/Gain、设备组合及校准状态保持一致。子帧组可关联校准主帧，类型与比较规则见 FR-02。

子帧组导入时可多次选择文件夹，所选文件追加到同一组，可在提交前逐条移除；移除只影响导入选择。中文界面使用中文帧类型名称，英文界面使用英文名称。拍摄参数使用与素材文件列表一致的树形展开控件。

素材库外层列表每行左侧显示名称、右侧以次要文字显示素材类型（子帧组、视频、主帧或图像结果）；类型无法确定时显示未知。名称过长时省略并保留完整名称提示，类型保持可辨识。点击进入详情；不显示大小、在线状态、复选框、批量编辑或每行更多操作及其创建源节点入口。组详情显示设备、滤镜、备注、拍摄参数、校准状态、校准主帧和可展开的子帧列表；备注位于滤镜之后、拍摄参数之前。单帧详情显示所属组、文件位置、大小和状态，组级参数在所属组查看。视频、主帧与图像结果详情显示文件、设备组合、实际滤镜及备注，支持修改和解除绑定。

子帧可通过列表移除，确认后取消该帧在素材库和组内的登记，磁盘文件保留；最后一帧移除后空组仍保留。组详情展示绑定时设备组合快照中的非滤镜成员及其产品名，以及本组单独选择的滤镜。

四类素材详情展示基本信息、设备滤镜及备注，子帧组额外展示组级拍摄参数、校准关系与文件列表。详情支持编辑名称、备注、设备和滤镜；子帧组可编辑帧类型、校准状态及组级拍摄参数，单帧不得单独编辑组级参数。编辑需保存或取消，离开未保存编辑时确认。移除素材或整个组的登记时保留磁盘文件；项目引用或校准来源引用须先解除。改变帧类型与已有校准引用冲突时须先解除引用。

四类详情采用紧凑标题行：名称右侧为编辑和更多操作，更多操作包含创建源节点和移除登记；子帧组名称下方汇总类型、帧类型、数量和校准状态。设备与滤镜默认收起，展开查看绑定快照及实际滤镜，拍摄参数、校准主帧和子帧文件保留各自展开区。

素材库默认展示全部素材；搜索框、筛选和导入位于同一工具栏，列表滚动时工具栏保持在顶部，空间不足时换行。校准主帧作为主帧在素材库中展示和筛选，不设独立校准库入口。搜索支持子帧组名称。

素材筛选按整个库中实际存在的数据提供素材类型、帧类型、主帧用途、设备组合、滤镜、校准状态、文件格式与存储位置分区及数量；同区多选为或、跨区为且，保留零结果已选项。筛选同时覆盖子帧组及单文件素材；清除筛选保留搜索文字。点击面板外只关闭面板，不触发后方控件，Esc 可关闭面板。列表默认按名称排序，组内默认按导入顺序排列。

子帧组、视频、主帧和图像结果可绑定设备组合并独立记录实际使用的滤镜；所选滤镜必须属于所选设备组合，组合无滤镜时可选无。未绑定组合时不选择具体滤镜，未知不等于无。绑定时系统保存设备及滤镜快照，设备或组合后续修改、隐藏不改变已有素材快照；用户可主动解绑或重新绑定，不因设备信息变化自动改写历史。视频保留名称、位置、可选设备与滤镜绑定和备注，且不绑定校准场。图像结果保存 ID、名称、文件位置、备注和 revision；主帧与图像结果的入口分类记录见 TECH-014。子帧文件保存组关系、文件名、路径及大小。专用数据库表及现行实现见 TECH-010、DEV-040/041。

- AC-12（已局部实现，待正式验收）：单文件主帧及视频、文件夹导入的子帧组分别可被识别与回读；子帧组保存共同信息与各文件位置；设备及滤镜修改后历史快照不改变；未知与明确未使用滤镜可区分；视频不提供校准场绑定。局部证据见 DEV-040/046/050/052，正式覆盖见 TC-011。

#### 项目组织规则

项目页以紧凑树形展示项目、文件夹和素材引用。顶部只显示搜索框；空白区域右键新建项目，项目或文件夹右键可在其下新建文件夹和添加素材，素材右键的同类操作作用于其父文件夹。新建行内输入名称，Enter 或失焦保存有效名称，Esc 取消；空白、非法或重复名称退出临时行并保留原记录，非法及重复名称提示原因；合法名称遇服务错误时保留输入供重试。双击或 F2 可行内重命名，Enter 或失焦保存有效变更，Esc 取消；空白、非法或重名保留原名称并在适用时提示。添加素材使用相同的目标位置，未选择项目时不可用。单击项目或文件夹行选择并展开或折叠，空白处取消选择；同项目节点可拖至项目或文件夹，禁止移动到自身和后代，失败保持原位置；移动选择器排除自身和后代。移除素材引用时说明保留素材库记录及源文件。右键或键盘上下文菜单提供详情、重命名、移动和移除，不显示行尾省略号按钮；方向键导航，搜索结果保留祖先路径。支持多选已有素材，并标记本项目已引用的素材；中英文、长名称和窄侧栏保持可用。

项目添加素材选择器默认展示全部四类素材及类型，复用素材库搜索框、实际数据筛选分区及浮层交互。显示已选目标项目及逻辑文件夹路径；切换搜索或筛选保留跨类型勾选，已在本项目引用的素材不可重复选择。使用批量引用接口一次原子提交，失败保留选择并提示；单次最多 100 项。

单击项目树中的子帧组引用，在原位置展开或收起组内文件。展开时按导入顺序分页读取，滚动可继续加载，空组及读取失败在组下提示。单击子帧查看原文件名、路径、大小和可用状态。组的项目别名仍可双击或按 F2 编辑，组级信息由右键查看组详情打开。子帧仅供查看，项目层级仍只记录整组素材引用。

项目支持多层逻辑文件夹，任意一层（包括项目根目录）可包含多个子帧组、视频或图像结果的引用，用于组织深空 Raw、Integrate 等阶段或按滤镜与月面区域组织素材。移动项目节点只调整逻辑位置，保留实际文件。MCP 按项目名称及逻辑路径创建和访问，系统内部以稳定 ID 管理关系，经公开接口与存储授权定位实际文件。素材名称全库唯一，项目节点名称或路径冲突须明确反馈。项目与节点字段见 TECH-007，现行公开后端与前端见 TECH-010。

项目 MCP 保留 10 个项目管理工具；批量添加素材仅按全库唯一的素材名称和可选项目别名定位，不要求类型或 UUID。项目读取默认查看直接子项，可选递归分页查看完整子树；对外素材详情不暴露内部引用 ID。分页游标和删除影响令牌作为不透明值原样回传。名称、路径和批量冲突、移动及删除保护遵循下述项目规则。

同一素材可以被多个项目引用，但同一项目中不能在多个位置重复引用同一素材；调整位置使用移动节点，不复制素材。项目节点允许别名：默认使用素材库名称，也可单独命名；项目内改名不改变素材库名称或实际文件名，素材库改名不覆盖已保存的项目节点名称，详情同时展示两者。

批量创建文件夹先整体检查，再原子执行：已存在的文件夹视为满足，缺失父目录自动创建；存在阻断冲突或非法路径时不创建任何新文件夹，并返回冲突。项目名称在项目库内唯一，同一父目录的文件夹和素材节点名称共用唯一约束；节点名称不能包含 `/`，逻辑路径以 `/` 开头，`/` 表示项目根目录。名称大小写与 Unicode 比较拟与设备名称规则对齐，跨平台细则仍需核实。

移除素材引用只移除项目关系，保留素材记录、真实文件和其他项目引用。空文件夹可直接删除；删除非空文件夹或项目先展示受影响文件夹和素材引用数量，经用户确认后删除相应项目结构及引用，保留素材库记录和实际文件。MCP 的确认机制须适配实际客户端与权限能力。

- AC-14：通过名称和路径一次创建多层目录，并在根目录及任意文件夹中加入多个素材，回读树及访问素材；验证跨项目引用、同项目去重、别名独立、批量冲突整体回滚和删除确认及文件保留；移动节点不移动实际文件；节点路径冲突及素材重名返回明确结果。实现和局部验证见 DEV-085、DEV-094、DEV-095，正式验收待执行。

管理和验证素材、设备、设备组合以及工作区位置等持久业务数据；贯通素材与设备、设备组合的关联，前端与 MCP 应能围绕同一批记录工作。前端支持查看、修改和解除素材或集合的设备组合绑定，沿用现有引用与保护规则。

设备库支持相机、望远镜／摄影镜头、光学附件、滤镜和其他。每台设备填写必需的名称、产品名及可选备注；名称区分设备实例，相同产品名可用于多台设备。设备类型、名称和产品名是创建必需信息，焦距、倍率等附加内容可放备注。设备组合可包含其他类型的条目。设备组合不再根据设备规格展示焦距和焦比计算。

设备组合表单将名称、设备选择和新增操作紧凑排列；新增使用加号并提供完整操作说明，狭窄侧栏允许名称换至上方。滤镜和其他设备支持多选。设备组合描述用户的一套设备，含必填名称、可选备注、最多一台相机、一个望远镜／镜头、一个光学附件，以及多个可用滤镜和其他设备；允许保存不完整组合。组合删除后保留记录，常规列表和新绑定选项不再展示。素材绑定后保留当时的设备信息以及实际使用的滤镜，该素材快照及校准匹配在后续素材工作实现。

设备名称在设备库内唯一，设备组合名称在组合库内唯一；产品名可以重复。归档仍占用名称，删除设备组合后名称可复用。前端表单说明名称唯一要求，提交重名时在名称字段提示用户修改。

设备及组合 MCP 使用名称精确定位，类型、归档筛选和排序使用公开英文枚举；提供查询、详情、创建、修改、归档恢复及经确认的删除。设备搜索名称及产品名，组合搜索自身及成员名称。工具说明使用英文，用户名称与备注原样保存；列表支持排序及与查询条件绑定的分页。MCP 仅调用公开 API，并在内部处理 ID 与并发版本。

- AC-11：创建、编辑、回读及搜索不完整或完整组合；相机、主光学设备和附件各至多一个，允许多个滤镜和其他设备；校验设备类别及并发版本，归档或删除后在相应入口正确隐藏。

- AC-10：五种类型均可通过统一表单创建、查看、编辑和搜索；名称及产品名缺失时显示校验错误，同一产品可登记多个不同名称的设备，其他类型可加入组合并回读。

- AC-01：登记并绑定设备组合后，在前端查看、修改和解除绑定；跨界面及公开接口回读相同的当前关系，重启后再次核对，并验证已有引用与保护规则。

### FR-02 校准场与绑定

#### 素材库中的校准主帧

每一份校准主帧独立保存，类型为 Dark、Bias、Dark Flat 或 Flat；即使相机和参数相同，新主帧也不覆盖旧记录或改变已有绑定。记录修订版本仅用于同一条记录的并发控制，不代表一份新的校准主帧。Dark、Bias、Dark Flat 可在相机及采集条件适用时复用；Flat 还需考虑设备组合、实际滤镜及拍摄时光路状态，组合与滤镜相同不保证 Flat 一定适用。已确认的类型、候选和温度规则见下文；实际光路状态不能由组合信息自动确定。

校准主帧记录名称、用途、文件位置、可选来源校准子帧组、相机及快照、采集参数、备注和工程信息；Flat 可记录设备组合和实际滤镜及快照。依据来源子帧组建立主帧时，未显式填写的参数从来源继承；未知值保持未知。校准主帧通过素材库主帧入口一次导入，已有主帧可编辑用途；同一文件身份只展示一条素材。移除独立校准库页面和重复登记入口。

素材详情展示主帧用途、相机、来源及采集参数；选择组合时滤镜限定于该组合。子帧组候选展示匹配、差异和未知；筛选与比较均不代表已执行校准或保证适用。

素材及校准主帧不引入结构化 `capture_date`；拍摄日期如有需要可放在名称或备注。系统的登记时间不能当作拍摄日期，也不从文件修改时间自动推断。

- AC-13（已局部实现，待正式验收）：登记同相机及参数的多份校准主帧后各自独立回读；新增主帧不覆盖旧文件或改变已有子帧组绑定；核对相机、参数及 Flat 光路信息与快照，未知保持未知。具体绑定和匹配验证以待确认规则为准，局部证据见 DEV-040/041，正式覆盖见 TC-012。

子帧组可绑定校准主帧；前端支持查看、修改及解除绑定，并沿用现有引用与保护规则。建立绑定只记录关系，不代表已经执行校准处理。生成主帧不在本轮已确认目标内。

Light 详情按 Dark、Bias、Flat 分项选择，Flat 按 Bias、Dark Flat 分项选择，其他帧类型不提供绑定入口；未知类型提示先确定。前端展示匹配、差异与未知的候选，差异与未知仅提示，不阻止绑定。比较相机、ISO、Gain、曝光、Offset、Binning、读出模式、滤镜和设备组合等登记信息；温度仅保存原始登记值，不由后端比较或限制绑定。

素材应描述其校准处理状态：已校准、未校准或未知；未知表示缺少可靠信息，不等同于未校准。此状态独立于 Light/Dark/Flat 等帧类型，也独立于是否绑定校准主帧。后续处理产生新数据，不自动更新原子帧组的校准状态；错误登记的人工纠正方式尚待明确。

- AC-02：登记代表性校准单帧与主帧，查看、修改和解除素材或集合的主帧绑定，在前端及公开接口核对关系并遵循现有保护规则。
- AC-06：使用参数匹配、存在差异和缺失的 Light 与校准场样本，核对 ISO、Gain、曝光时间等适用参数的比较；差异和未知均可见且不阻止绑定，不比较温差。前端、MCP 和直接 API 一致核验。
- AC-07：能够区分并查看素材的已校准、未校准和未知状态；仅建立校准主帧绑定不会将状态视为已校准。状态证据和变更流程待确认。

### FR-03 Workspace 与多磁盘

覆盖工作区与多存储位置的管理，验证素材登记、路径及前端展示与数据库保持一致，并关注离线、迁移、恢复和导入过程中的可观察状态；具体覆盖按历史契约及用户后续确认确定。

新增存储位置表单的路径标签使用“文件地址”；路径仍按现有规则验证。

存储位置列表默认显示状态及磁盘剩余；未设置位置限额时不显示位置用量摘要。设置限额时显示本位置已用及限额；离线或空间未知时显示空间不可用。空间紧张或接近限额时突出相应信息。磁盘剩余不代表保证可写入的容量。

存储位置的下拉面板直接显示路径及当前可用容量上限参考，并支持编辑名称和容量上限；面板不展示本位置已用，容量上限说明通过标题旁提示图标查看；留空表示不限额。修改后启用保存按钮；保存成功后关闭并提示，取消或点击面板外部放弃未提交的修改。保存失败保留输入与错误提示，部分成功须明确显示已生效内容。容量说明在图标悬停或键盘聚焦时显示，移开或失焦后消失。移除继续走既有迁移确认。菜单不再提供上移、下移，拖拽手柄提供键盘排序；面板在原位置向下展开并参与页面布局，侧栏滚动区域随内容扩展；沿用原下拉框宽度，紧凑排版；长路径可查看，内容通过侧栏滚动查看，不提供路径复制按钮。名称和限额保存涉及独立操作，部分成功时须明确展示并保留可重试的未完成内容。

- AC-08：核对不限额、有限额、离线及空间未知的列表和详情，区分磁盘空间与本位置用量，并验证空间紧张提示。

- AC-03（目标）：在可用环境中核对多位置素材的实际文件、登记及界面回读；重启后关联仍可查。涉及真实双物理盘性能或故障场景需在可用硬件上独立验证，不能用同盘多目录冒充。

### FR-06 统一素材导入体验

全部素材页不重复显示标题；搜索及筛选栏右侧显示导入素材按钮。统一入口提供子帧组、视频、主帧和图像结果；主帧导入时选择用途，校准用途填写相机、参数、来源及适用光路。子帧组可追加文件夹，其余各选一个文件。导入页不选择项目，之后在项目中组织素材。取消选择不导入。

子帧组配置名称、帧类型、备注、可选设备组合、实际滤镜、可选拍摄参数和校准状态，参数未知允许导入。Light 和 Flat 可在导入时选择合适的校准主帧，也可稍后绑定；温度不参与比较。默认名称使用文件夹名、未知校准状态及滤镜不推断为已知。视频、主帧与图像结果配置名称和备注，按用途填写设备组合和滤镜；校准主帧补充可选相机、来源子帧组及拍摄参数。视频不提供校准绑定。具体滤镜只从已选设备组合中选择；组合没有滤镜时可选择无。子帧文件列表默认显示数量，允许展开。

两种存储模式共用类型选择后的配置体验；仅登记保留原位置，复制模式写入工作区并保留既有恢复及按需多盘能力。仅登记模式优先使用宿主系统窗口，窗口不可用时保留服务端浏览回退；登记选择器不显示白色辅助窗口。路径按现有权限校验。页面以“导入”为主要操作，内部执行预检，必要的差异或未知信息先展示并等待用户决定；若素材导入成功但校准绑定失败，明确区分结果并提供重试绑定，避免误导重复导入。建立绑定不自动改变校准状态。

仅登记的文件选择窗口标题跟随界面语言，中文为“选择天文素材”，英文为“Select Astrophotography Assets”。

- AC-09：两种存储模式分别核对四种入口、文件或文件夹选择、取消及重新选择、各类型配置、自动预检与导入。导入页不展示项目选择。未知可保留，Light/Flat 可核对差异后绑定，绑定失败时显示部分成功并可重试。验证文件保留、窗口回退和导入恢复。现行前端见 DEV-040，历史页面见 DEV-018 与 TC-001。

### FR-04 Agent 素材导入方向

每次导入一个素材：一个 Master Frame、图像结果或视频文件，或选择一个或多个文件夹中的子帧作为一个子帧组。Agent 依据文件名、文件夹名及用户说明识别和补充信息，不读取 FITS 或其他文件元数据进行识别；信息不足时保持未知并询问用户。设备及校准绑定遵循 FR-01、FR-02。原混合素材自动分组、依据元数据识别和逐组提案流程已舍弃，旧混合导入工具已移除（DEV-041）；现行 MCP 见 DEV-086。

用户在 Agent 对话中授权后，MCP 可直接提交目录导入，宿主预检并返回异步任务；主帧导入或修改时指定校准用途及参数，项目组织和校准绑定在独立操作中完成。工具按素材、校准及项目公开结构化参数和英文枚举。设备与组合和项目采用唯一名称，素材及校准主帧允许同名，歧义时使用工具返回的引用。项目节点使用逻辑路径；已引用主帧的用途、采集和光路字段受保护。

- AC-04（局部实现与验证）：分别以单个主帧、单个视频和一个子帧文件夹为输入，在公开接口、MCP 与前端核对各自导入及回读；核对名称缺失信息时保持未知或询问用户，不依赖文件元数据识别。真实客户端与独立 MCP 进程验证单独报告。

### FR-05 可复现测试数据与联合验证

素材库管理测试数据覆盖子帧组、视频、主帧、图像结果和校准主帧。生成的 FITS 使用固定像素值，不使用随机数据；测试集可安全重复生成到同一目录，按五套设备组合及适用滤镜配置导入，项目中组织支持引用的素材。FITS 图像超过 200 万像素，无须模拟相机原生分辨率；视频为 720p、每段 10 秒。素材以文件名和目录支持后续识别测试，测试清单仅作预期结果对照，不作为 Agent 输入。图像与视频均为合成样本，不要求模拟真实天体或图像处理缺陷。

主要使用程序生成的 FITS 测试数据，以可复现方式构建素材管理和校准关联样本，并用于实际链路联调。生成的数据属于合成数据，不能冒充真实拍摄样本。通过文件名和用户提供的信息覆盖主要帧类型、多设备、多滤镜以及 ISO/Gain、曝光等参数的匹配、差异和缺失；校准状态与后续匹配样本按已确认规则补充。是否补充真实数据待确认。

- AC-05：记录生成方法、参数及生成结果；生成覆盖主要帧类型、多设备、多滤镜及名称信息缺失的实际文件，执行相关导入、匹配、绑定与回读，并核对原始 FITS 数据及已有元数据得到保留。保留元数据不要求 Agent 读取或利用其识别。记录环境、实际步骤、结果和未覆盖范围。

### 侧栏刷新入口

侧栏顶部提供常驻刷新按钮，切换节点、素材和设置时保持可用，用于重新获取已访问页面的共享数据。

### 素材入口

首次进入素材及点击素材入口返回主页时，默认显示“全部素材”。

单张和批量导入页面不展示“查看存储设置”或手动添加其他路径入口；继续提供各自适用的文件和文件夹选择。系统选择器不可用时仍可使用已有备用选择流程。

### 紧凑素材导入表单

四种素材使用紧凑、双语和可折叠的表单。选择设备组合后披露相机、主光学、附件与其他设备，滤镜单独选择。图像结果未指定组合时，设备与滤镜默认折叠。子帧组及主帧按适用范围填写拍摄参数，感光度可切换 ISO 与增益和偏置而不丢失已输入值；新建像素合并默认 1，允许未知或自定义。通过 MCP 导入主帧时，有来源组且省略像素合并就继承组值。读出模式未填为 null。来源子帧组可选；已有参数在编辑时应完整保留。校准绑定仅在适用的子帧类型展示。导入动作在滚动时保持可见。

像素合并与相机读出模式均放在“更多参数”，折叠摘要展示当前值。普通亮场及未知主帧也支持来源子帧组和拍摄参数；按当前用户输入保存，来源或设备后来改变不自动改写已有主帧。

子帧组、视频、主帧和图像结果的名称在整个素材库全局唯一；名称比较忽略首尾空格、大小写并按 Unicode NFC 规范化。导入和重命名遇到重名时拒绝并以当前界面语言提示；移除素材登记后名称可重新使用，子帧文件名不参与唯一约束。

素材 MCP 使用 13 个名称驱动工具，Agent 使用素材名称而非 UUID 查找、编辑与校准绑定。允许向已有子帧组追加明确选择的文件或文件夹，并保留共同参数；导入和追加提供短任务号查询。校准候选保留差异项，差异及未知只提示，不阻止绑定；类型与引用校验仍有效。文件夹检查只列文件，素材系统不读取文件元数据。

用户授权 Agent 整理混合文件夹时，默认由 Agent 基于可获得的信息制定逻辑分组，再逐组提交具体文件路径创建或追加；引用模式记录各文件原始路径，复制模式记录受管理副本。系统不将文件名中的线索当作已验证参数，无法确定的信息保持未知或由 Agent 向用户确认。除用户明确要求外，不移动、重命名或删除原始文件。此规则不恢复此前舍弃的后端混合导入自动分组或元数据读取方案。

### 设备组合列表

设备组合默认展示全部未归档组合，包括配置不完整的组合；搜索支持组合名称和成员设备名称。列表不提供草稿或已配置筛选，也不显示“已配置”状态；不完整组合提示缺少的相机或主光学设备。搜索框旁的紧凑菜单可进入已归档列表或返回在用列表，归档及恢复行为保留。
