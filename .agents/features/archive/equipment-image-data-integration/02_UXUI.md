# 设备、素材及存储交互交接

依据 PRD v0.18 的已确认决定及 DEV 记录。本文整理现有侧栏的交互规范。历史原型和已确认视觉基线见[设备与摄影素材库专题](../../../archive/04-equipment-optical-trains/00_FEATURE_INDEX.md)。本轮浏览器批注、现场截图和前端实现提供增量依据，真实宿主视觉验收待执行。

| 界面 | 操作与状态 | 可追踪依据 |
| --- | --- | --- |
| 设置首页 | 入口依次为「设备」「软件管理」「配置」，进入详情后可返回设置首页。 | AC-23、DEV-080、TC-080 |
| 设备 | 「我的设备」「设备组合」两标签。新增先选类型，名称与成像关键字段置于基础区。高级折叠保留已有值，校验错误可定位到高级字段。 | AC-16～17、DEV-007～008、TC-009～010 |
| 素材导入 | 「全部素材」在「项目」左侧，列表操作提供「导入单张」「批量导入」。复制直接打开文件选择，登记进入路径表单。分类和项目在内页选择。隐藏策略和首选位置摘要，预检可展示实际目标。批量复制可选择多盘参与位置并查看结果。 | AC-18～19、AC-28、DEV-020、DEV-052、DEV-113、TC-020、TC-052、TC-113 |

## 交互状态与验收交接

- 使用当前宿主主题、已有展开箭头和菜单反馈。核对窄侧栏、中英文、键盘确认与 Escape 关闭，以及当前选中状态和焦点。
- 加载或提交期间提供可见状态。保存失败保留可恢复输入或原有树关系。任务未知总量时展示阶段，结束时展示实际成功或失败结果。
- 真实宿主取证使用既有 8188 预览约束和隔离数据。新增位置的两份现场截图及重复通知诊断见 [DEV-111](04_DEV_LOG.md#dev-111-新增存储位置的两次路径诊断)。
- 产品待决的组合删除恢复及 Agent 审批交互见 PRD Q-02、Q-03。

## 聊天内分组审批

Agent 展示明确分组和需补充信息项。每组原生确认展示文件数量与示例、提案 ID 和摘要、目标项目、登记或复制方式、确认时的工作区、设备/组合和校准主帧或缺项。校准主帧存在差异或缺少字段时，按主帧分别展示「冲突」与「缺失」项目；设备组合保存配置不完整时以「配置缺项」展示而不是冲突。用户可通过组状态查看完整清单。批准只作用于当前组，明确拒绝保留拒绝回执，关闭确认保留待定。状态可显示导入未完成、绑定未完成或最终结果。绑定失败提供重试原关系写入的入口，导入事实和素材 ID 可单独查询；对分组导入在任务框重试未完成帧时继续沿用原批准，不要求重新确认。客户端仍需支持原生确认并由本机操作者显式信任。
