| 宿主扩展 | V3 注册通用节点和 183 个 Siril 命令节点。Siril 在原生库、侧栏和命令目录按 18 个双语一级图像处理目录展示，色彩操作有 4 个子目录。扩展使用原生 aiohttp 状态和业务 API、Vue 原生 DOM Widget 和侧栏。未启用本地授权或依赖异常时状态反映实际门槛。 |
| 绘图 | PNG 像素随新保存工作流往返；保留 PNG→LoadImage→IMAGE，真实宿主 IMAGE 路径问题仍待验证和独立修复。 |
| 前端 | 单侧栏含 Nodes、占位 Assets、Settings，宿主主题语言、真实节点目录、书签和本地画布添加。通用资产拖入节点、真实帧型过滤、完整会话详情还未完成。 |
| 本地存储及资产 | 多工作区、默认位置、受控迁移、可清理缓存、reference/copy、受控位置重绑定和资产分页。保留离线位置及资产身份，完整会话、观测点、校准关联和跨机器路径复现仍待定义或实现。 |
| 设备与光路 | 四类设备、光路单配置、归档和受保护删除。历史快照可兼容查询。 |
| 科学处理 | Siril 1.4.5 探测与验证、完整命令目录、183 个 headless 节点、路径执行与三种命令的候选比较。PixInsight 处理未实现；通用科学文件与高资源压力场景未完成验证。 |
| MCP | 默认 version 和 connection_status；条件注册六个设备/光路只读工具，包内技能加载已接线，当前没有产品技能。配置独立库令牌时还注册七个素材库工具，敏感写入由受信浏览器确认。Siril 和通用画布编辑由宿主 UI／节点负责。 |

后续产品范围包括完整资产模型、Siril/PixInsight 独立受控操作、工作流发现和执行回执、知识库、记忆、实验及 Agent Skills。供 MCP 操作画布需目标 session、图版本、受控命令和真实回执；断线及版本冲突须显式返回。知识拟支持许可与出处追溯、无模型全文检索和可选向量能力。记忆需显式授权、用户纠正和删除，区分人工、Agent 和系统行为。实验需保存输入、参数、版本、输出、指标和失败，能重放；外部 Agent 管搜索策略。产品技能依赖已验证的业务工具，工作区开发技能不进入包。

## 运行状态和可执行行为

- `status_api`、`drawing_node` 各看路由和节点实际注册。数据根路径已知、节点已注册、配置文件中有 CLI 路径都不能分别证明数据库可用、画布可写或正式处理可运行。
- `storage`、`database` 以初始化和健康检查为准。Assets 和设备操作还要通过本机部署条件。软件配置接口可用与某个已安装软件通过验证是不同状态；`processing` 依赖本机业务及 Siril 实际 ready。
- 后端现有资产 API 支持预检、引用或副本导入、回执、物理文件可用性和重新定位。Vue Assets 支持虚拟组织、手动元数据和校准条件确认。元数据推断和自动科学校准仍属后续能力。较早文档的“无素材服务”已被当前代码替代。
- 当前 Settings 依次包含 Storage、Environment、Software、Equipment、Knowledge、Memory、Agent、System。导航出现与业务可用是两回事。Storage、Environment、Software、Equipment 有现行配置或管理；知识、记忆等仍须服从状态与实际路由。
- 图像处理链覆盖单帧二维单色或三通道 RGB FITS。FITS Source 可选已登记资产，Image Path 节点保留输入路径，AutoStretch 经可信本机验证后可输出另一个下游节点能消费的正式路径。FITS 之外的格式、通用序列、完整深空预处理和跨子图自动候选，不能从该链推断支持。
- 预览最长边为 512、1024、2048、4096、0（原尺寸），默认 1024。画布布局值 480×320。配置 API 校验旧的可选 canvas 字段但只写 PNG 最长边。Siril 正式运行不使用显示缩略图。

## 后续能力的依赖与明确边界

| 方向 | 前置及不可越过的契约 |
| --- | --- |
| 素材库与校准 | 持久会话、帧分类、设备/光路和观察信息。区分原始观测值、推断和值的用户确认，匹配证据不足时显式待确认。 |
| 专业软件扩展 | 新软件需验证官方接口、平台及授权。目标 Bundle 管理软件专属操作，公共前端消费通用接入。PixInsight 不共享 Siril CLI 假设。 |
| 外部工作流 | 发现已注册节点和执行已保存图可以与在线画布操作分别交付。在线改图需要目标 session、图版本、命令、保存/撤销和回执。 |
| 知识 | 文档有版本、语言、出处及许可；可先用关键词索引，有依据再选向量。缺少可靠来源时保留未解决。 |
| 记忆 | 本地持久记忆与图运行历史分开。授权后采集，区分 human/agent/system，能查看、改正、撤回、导出、删除。一次执行不等于偏好。 |
| 实验与 Skills | 实验依赖可追踪运行快照、输入、参数及比较指标，能预算、取消、复跑。Skill 依赖已经开放的操作，缺失时显示不可运行；与开发者技能分开打包。 |

详见 [后端](backend-overview.md)、[前端](frontend-overview.md) 和 [MCP](mcp-overview.md)。
