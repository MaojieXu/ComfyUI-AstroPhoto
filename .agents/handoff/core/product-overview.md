# 项目概览与代码接手地图

AstroPhoto 是运行在 ComfyUI 中的本地天文摄影工作台。工程由 ComfyUI Extension 和独立 MCP 服务组成。主要使用路径是操作者在侧栏登记本地素材、设备和光路，在宿主图中配置并运行专业处理节点，再从工作区找到可追溯的结果。外部 Agent 通过 MCP 查询宿主和已开放的业务能力。截至 0.0.1，Agent 的业务能力只覆盖受控设备与光路读取。

## 从哪里进入实现

| 工程部分 | 入口与职责 | 接手文档 |
| --- | --- | --- |
| ComfyUI Extension | 根 `__init__.py` 暴露 V3 入口，`on_load` 装配运行时并注册原生路由；`nodes/` 定义绘图及科学节点。宿主管理图、节点注册、队列和执行。 | [后端概览](backend-overview.md) |
| 业务服务 | `astrophoto/` 按域管理存储、资产、设备与光路、Siril。服务拥有 SQLite 和持久文件，路由提供状态及受控操作。 | [后端概览](backend-overview.md) |
| 宿主前端 | `frontend/entry.ts` 聚合 Vue 画板和 React 侧栏。两者挂入宿主扩展，业务请求经宿主 API。构建共用 JS 和 CSS。 | [前端概览](frontend-overview.md) |
| MCP | `mcp/src/astrophoto_mcp/` 提供独立 stdio 服务，经公共 HTTP 访问宿主与 Extension。默认提供诊断，启用指定本机授权后暴露设备只读查询。 | [MCP 概览](mcp-overview.md) |

## 接手时优先区分的运行边界

- **Addon、宿主、依赖版本。** 开发环境与 ComfyUI Python 独立，真实宿主的兼容范围依据实际验证记录。Node schema 可存在，运行时仍可能因 Siril 或存储不可用而拒绝。
- **业务事实与文件。** 默认数据根在用户目录下，业务索引和关系保存在 Extension 的 SQLite。reference 使用原路径，copy 写受管副本，正式产物进入工作区，候选 PNG 进入 Cache。FITS 原件、科学输出及显示代理各有自己的生命周期。
- **画布与执行。** 工作流保存时的 widget 值、提交 prompt 时的序列化数据和队列结果分别核对。侧栏能在本地画布建节点。面向外部 MCP 的画布桥是后续工程。
- **业务用户与外部进程。** 本机浏览器授权、MCP 诊断及设备只读分别走各自权限。外部 Agent 通过接口消费结果，业务库由 Extension 持有。
- **可交付与可证明。** 当前实现、目标状态、特定快照下的真实宿主证据要分开。先查 [当前能力](capabilities.md)，再读 [跨端架构](architecture.md)、[验证与证据](verification.md) 和 [初版工程边界](first-release.md)。

## 用工程链路理解当前仓库

| 从哪里开始 | 谁提供结果、哪里可以继续 | 当前边界 |
| --- | --- | --- |
| 发现宿主与能力 | ComfyUI 加载 Extension 后，状态 API 汇总实际注册和服务条件。MCP 可单独诊断宿主连接。 | 版本号是识别依据，暂无跨包握手；状态可用不能替代特定动作授权。 |
| 引入素材 | 浏览器取得受控导入预检和 operation 回执，后端登记 Asset，按模式保存外部位置或发布副本。 | 通用会话、帧筛选及自动校准匹配不在现有完整链内。 |
| 配置设备及光路 | Settings 中的当前配置和持久化设备可供浏览器读写，合规令牌下 Agent 可查询。 | 历史 revision 只兼容读取，归档、解除引用和删除有区别。 |
| 处理与回读结果 | FITS 来源和路径接入宿主队列。Inspector 候选供判断，正式结果有文件和运行回执，可链接给后续节点。 | 目前的已验证链聚焦 Siril AutoStretch。目标图编辑、其他软件和完整预处理链需独立交付。 |
| 安装与交付 | 开发者在 checkout 一起工作，运行时通过两个发行物安装。 | 源码同步与目标平台上的装机验证分别进行，详见 [双包发行](release.md)。 |

目前对后续决策影响最大的是 P0 前端迁移。已定稿内容界定 Vue 统一栈、资料库归属、Siril Bundle、两种画布和复用规则，现行 Vue/React 接线仍是迁移前的行为基线。需要取舍路由归属、材料准备、兼容或新构件范围时读 [初版工程边界](first-release.md)；比较屏幕行为时读 [决策与交互风格](decisions.md)。
