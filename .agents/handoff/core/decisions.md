# 兼容决定与历史差异

- 统一 V3 注册，保留 `vue-basic`、`CUSTOM_VUE_COMPONENT_BASIC` 和旧 prompt 形状。用户要求保留真实 IMAGE 的既有问题范围；像素保存修复已另行验收。
- 侧栏继承宿主主题和语言，撤下旧 General/独立开关；原型中的观测地设置行、会话树及示例数量是旧设计。保留固定宿主参考版本带来的书签和画布依赖。
- 光路由旧版本发布流程改为单份可编辑配置。旧 revision 保留只读兼容，旧写接口返回 410；删除需版本和引用检查。数据库仅有统一基线，旧开发库需显式选择新隔离数据根。
- 首期科学端口最终采用 IMAGE_PATH。旧 ASTRO_FRAME 或 STRING 线需要重接；输出传文件路径，科学元数据与内容哈希在处理回执中。保持原文件独立，不将精度缩成通用 IMAGE。
- Siril 可信本机直读范围与导入根授权分开。选用固定版本及受控 CLI，验证工作副本的实际处理。候选与正式产物分别有寿命和写入位置；Inspector 编辑同一个宿主节点。
- 知识、记忆和资产保持独立数据所有权；MCP 不读数据库。产品技能仅从独立包的技能目录发现。现在需持续验证的边界有共享/反代部署、真实宿主授权、多平台和多卷恢复、Siril 资源压力、复杂子图候选和线上包状态。

## 决策应保留什么

下面记录仍约束代码、验收或兼容性的决定。当前执行行为以工作树源码为准，已定稿的需求约束后续交付，设计草案描述候选实现，旧任务笔记提供决定缘由和特定验收证据。

| 决策主题 | 当前约束及可观察结果 | 改动时要重验 |
| --- | --- | --- |
| 宿主优先 | 保留原生 V3、PromptServer、扩展挂载、画布与队列。服务分域放在一个扩展进程，MCP 单独运行。复用宿主对外接口，私有接口只在显式版本适配层内使用。 | 启动、重复加载、节点 Schema、撤销与工作流重开；HTTP 对接不得另设业务 Server。 |
| 生命周期和拥有者 | Python 导入只定义、解析配置无写入。V3 on_load 初始化存储与注册路由。浏览器挂载处理 UI，不能借挂载初始化持久状态。短事务登记元数据，长任务在受控工作目录运行。 | 首次启动、失败降级、无副作用导入、重复注册及卸载；客户端请求取消后过期结果不能覆盖新状态。 |
| 原件保护与路径 | Asset Import 依赖显式导入根。Siril 的合规服务器本机直接路径是另一条受信读取链。Workspace、Cache、Data Root 承担不同归属。受管副本和正式输出都独立，删除或恢复依赖身份、标记和引用。 | 离线盘、别名/链接、跨卷、写入中断和并发；原件指纹一致，旧根或原文件处置有清楚的原因与用户操作。 |
| 数据库与光路 | 只保留一个可修改的当前光路配置。读取旧版可使用默认或最近快照，旧快照只读。版本令牌防并发覆盖；设备删除保护实际引用。库不兼容时保留文件并报 `DEV_SCHEMA_RESET_REQUIRED`。 | 用已有旧库、同版本异构库和新库分别检查；读取旧快照不写回，删除光路和清理旧记录必须同事务。 |
| 科学链及旧图 | `IMAGE_PATH` 是稳定连线类型，路径字符串不承载像素。手工路径节点只传值。实际读取与执行由可信节点校验。FITS 精度、头信息、参数和结果靠样本验证及回执追溯。 | 节点 ID、Widget key 和已保存连线；直接路径及 Asset ID、单色与 RGB、候选和正式结果、源未改写、二级串联。 |
| MCP 权限与契约 | 维持版本 Tool 的结构化响应和连接状态的原始文本响应。只读设备工具的枚举条件和服务端允许条件分别实施。MCP 不读底层库，不执行任意命令，不将协议层技能变成业务授权。 | 默认工具枚举、失败响应、独立安装握手、同源浏览器与只读令牌请求分别验证。 |
| 发行 | 根 pyproject 控版本，MCP 单独出 wheel/sdist，Registry 交付 Extension 运行文件和生成前端。MCP 先上 PyPI。源码开发环境用本地 workspace，不污染宿主 Python。 | 不同安装形态、产物白名单、公开依赖和目标宿主安装；不能由本地测试推断线上已发布。 |

## 现有界面风格与交互基线

| 界面 | 当前需保留或对照的行为 |
| --- | --- |
| 侧栏整体 | 单一 `astrophoto.sidebar`，宿主管容器与关闭。紧凑主导航按内容宽度靠左，显示 Nodes / Assets / Settings，通常默认 Assets。切换保留已挂载视图的状态，未保存设备/光路编辑可拦截离开。 |
| 主题、语言、键盘 | 颜色取宿主语义变量，扩展有自身样式范围；跟随 Comfy.Locale，主要语言 zh/en。选中、默认、焦点各有可辨识样式，方向键/Home/End 移动焦点，Enter/空格激活。独立语言主题开关已退出。 |
| 节点目录 | 数据来自真实 `/object_info`。显示层去 AstroPhoto 分类前缀，实际 ID 和分类不变。分类导航、搜索与展开、悬停只读缩略图、拖放及点击添加留在节点目录。原生收藏使用版本相关的宿主设置，保留非 AstroPhoto 书签。 |
| 搜索工具栏 | 仿原生节点库的一行布局，搜索、筛选、排序。输入法组合结束再更新搜索，清空可触发刷新。菜单 Escape 返回触发器，过滤与排序语义由各业务页控制。节点按真实注册 ID 和分类解析，素材筛选的未实现部分不能从旧原型推断已完成。 |
| 存储与环境 | 分组标题与分隔，宽面板双列、窄面板堆叠；导入模式为带说明的原生 radio。工作区列表有状态标记及菜单。危险或路径操作复用宿主确认/输入弹窗，异步完成以实际回执更新。 |
| 设备、光路 | 资料以列表、表单、摘要与折叠详情分工。子标签可重复点击回该类列表，保留各自搜索和筛选；切换经未保存确认。错误保留输入，版本冲突有复查路径。单选/多选使用已移植的宿主 Vue 实现，目前通过 React 包装。 |
| Siril Inspector | 对照图有并排、单图和 wipe；空间对齐可证明时才开放 wipe。参数写回画布 Widget，尊重只读、仅选择模式和撤销。单色禁用 RGB 联动。节点预览与 Inspector 使用相同 PNG 预览设置。 |
| 绘图 Widget | 保存像素和队列上传分开。损坏的内嵌 PNG 显示可翻译错误，旧工作流保存的空值无法重建历史像素；加载不得用临时空画板覆盖有效已保存内容。 |

## 官方源码复用和界面验收

设计、修改或修复时先拆分容器、控件、交互、路由、校验与持久化等实施项，逐项核对与目标宿主版本匹配的官方实现。公开可用时直接用公开接口；内部实现可移植时选最小可用源码，记录上游版本、路径、符号、许可、依赖和本地差异；官方仅覆盖部分时，复用已有部分并明确自行实现的缺口。前端保留可访问性、相同键盘语义、主题、焦点与状态反馈。具体组件和函数见 [前端概览](frontend-overview.md)。

对当前 P0 前端迁移，以同一宿主主题、语言、面板宽度和业务状态逐模块对照迁移前后。验收包含经典画布和 Nodes 2.0、保存重开、原生撤销和真实下拉交互。布局、入口或操作顺序有明显变化时记录差异并确认。素材页不在功能迁移范围，是否保留 Assets 标签和完成后默认页仍未定。已批准的方向、草案及其工程阻塞见 [初版工程边界](first-release.md)。
