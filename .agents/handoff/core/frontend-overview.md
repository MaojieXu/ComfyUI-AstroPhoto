# Frontend 需求、现行流程与验收边界

设备页面现为五类统一表单，名称与产品名必填，备注可选；设备组合使用单记录，附件单选，滤镜和其他设备多选，焦距和焦比计算已移除。详细契约见 `docs/equipment.md`，真实宿主验证以活动 Feature 记录为准。

## 需求与当前基线

用户在 ComfyUI 内完成找节点、建图、绘图、配置存储、管理设备和科学预览。侧栏、画布、主题、语言、保存、撤销和队列依附宿主。主要操作应保留现有导航顺序和反馈，旧工作流打开后仍能识别节点、端口、Widget 键、像素和科学参数。

公共界面、画板、资料库和科学交互统一使用 Vue。`extension/frontend-entry.ts` 将公共 `frontend/src/main.ts` 和 Siril Bundle 组装为单一 Vite 构件，仍由 `js/main.js` 和 `js/assets/main.css` 交付。Vue I18n 与宿主主题、语言协作，公开宿主 app/api 通过相对路径连接。侧栏只注册一个 AstroPhoto tab，包含 Nodes、Assets、Settings。Assets 提供 Projects、All Assets 和从 All Assets 进入的 Calibration Library，已有设备草稿时恢复 Settings。

## 用户操作怎样流转

| 场景 | 基础流程与处理边界 |
|---|---|
| 侧栏首页导航 | 点击或键盘激活顶层 Nodes、Assets、Settings，分别进入目录、Projects、设置模块列表。编辑中的设备、光路和素材沿用离开确认。导入页专用链接直达 Storage。 |
| 搜索、收藏和加入节点 | 从宿主对象信息读取实际已注册的 AstroPhoto 节点，按显示名、ID、类别等搜索并作筛选、排序、缩略预览和收藏。点击或拖放取当前画布和坐标，通过原生工厂创建节点并进入宿主变化边界。图未准备、只读、仅选择或未注册时拒绝写入，插入失败清理现场。 |
| 绘图与旧工作流 | 节点挂载独立 Vue 画板，工作流 Widget 值保存 `{image, canvasDataURL}`。重开恢复 PNG，过期异步恢复不得覆盖新绘制，坏 PNG 提示。队列序列化另把当前画布上传至宿主暂存空间，返回 `threed/<name> [temp]`，网络或 JSON 解析抛错返回空图像引用。HTTP 错误但含 JSON，或缺文件名的回执，当前缺显式守卫，需核对是否产生无效临时引用。Python LoadImage 的既有路径故障单独验收。 |
| 素材、存储和环境 | Assets 懒加载素材和虚拟组织。浏览器选择、预检、导入回执、外部引用重绑、Collection、目录和校准通过扩展接口。素材页审批入口已移除，Agent 中的审批决策方式待实现。配置页按序列出已登记的位置。删除位置时从其余可用位置选择迁移目标，最后一个位置受保护。默认导入方式和预览分辨率使用共享配置版本。导入等长期操作显示阶段、回执及失败状态。环境设置控制候选 PNG 的最长边，正式 FITS 尺寸由处理链决定。 |
| 设备与光路 | 页面按类型列出设备、表单和详情，支持归档与受约束删除。光路编辑器从真实设备中选择组件，维护配件顺序和滤镜。字段校验错误保留输入，过期保存按新版本处理，离开未保存编辑前提示。当前界面维护单一配置，旧 revision 由后端保留兼容读取。 |
| Siril 和科学 Inspector | 软件设置探测、验证并保存可执行路径。FITS Source 选择已登记资产，Image Path 可提供本机路径。Inspector 以当前源和参数请求候选，取消过期作业与请求，屏蔽迟到响应，并在卸载时清理定时器、监听和图像 URL。两张图可对齐时支持擦拭对比，否则回到并排。参数修改走宿主原生变更边界，正式结果通过队列另行生成。 |

通用请求经宿主 `fetchApi`，分别处理调用方取消、超时、网络、HTTP 和非法响应。侧栏重渲染时同容器复用，换容器销毁旧挂载，释放资源。UI 测试应观察实际回执、图变化与清理，视觉可打开只是其中一项。[后端概览](backend-overview.md) · [兼容与界面决定](decisions.md)

侧栏刷新时撤下旧目录与添加入口，失败给错误与重试。目录、详情、收藏解析和拖放共享排除示例后的范围。顶层收藏与具体路径分别管理，单次宿主写入确认 HTTP 回执后同步共享状态，失败时回读。设备草稿限侧栏会话，默认 Assets、有有效草稿优先 Settings。

侧栏使用画布薄适配，点击按宿主可视中心，拖放用目标版本默认原生节点库的坐标转换。拖放只接受当前目录与交互会话，切图或切标签不能提交旧拖放。共享构件已在 Windows / Chromium、0.46.0 / 1.59.6 的 Classic 与 Nodes 2.0 验证主图和子图、放置、失败回滚、Undo/Redo、重开、精确收藏，以及默认 Assets 和 Settings 联动。该证据适用于此组合。

## 当前已定稿的 P0 迁移需求

v1.3 要求活跃生产入口统一 Vue，移除 React 源码入口、跨框架包装、依赖和专用测试工具。保留原生侧栏、目录与图操作、存储和环境、设备光路、科学 Inspector、绘图存量工作流和视觉交互。设备光路归资料库界面，资源列表、详情、搜索和空态可复用，领域约束仍在设备和光路业务内。

Siril 专属配置、分组命令目录、中英文节点内介绍、共享 CLI 日志、节点交互及候选预览归 `extension/siril/`，公共前端消费 Bundle 接口。处理软件未安装或 Bundle 未接入时，通用 FITS、预览设置和其它公共界面保持可用。复用目标宿主的公开接入和适合移植的组件，见 [初版工程边界与 FR-01–09](first-release.md)。

## 证据与补发定位

- 正式迁移验收组合为 ComfyUI 0.46.0 / Frontend 1.59.6。经典画布和 Nodes 2.0 都需用旧工作流验证节点、连线、Widget、保存重开、撤销和正式路径。按相同主题、语言、宽度和业务状态逐模块对照，核对仅 Vue 的干净依赖与构件。在绘图前端验收到 `[temp]` 引用提交为止，端到端 IMAGE 执行单独留存结果。见 [绘图 IMAGE 的独立复验](verification.md#绘图-image-的独立复验)。
- 历史真实宿主 0.45.0 / 1.59.1 证明了部分界面交互、绘图重开和存储操作。JSDOM 的宿主替身测试与 Chromium 的真实 Canvas 测试覆盖范围不同，均不能替代目标宿主对实际选择器、画布和迁移构件的验收。[验证](verification.md)
- 审查挂载、Siril 接线、请求或组件细节时补发 `module/frontend/implementation.md` 和相应地图。宿主与 API 用 `source-index-sidebar.md`，领域页面用 `source-index-sidebar-domains.md`，画板和构件用 `source-index-widget-tests.md`，逐用例与断言用 `source-index-frontend-tests.md`。

### 素材工具栏适配补充

All Assets 搜索使用既有官方 SearchField，旁边的 Reka Popover 承载排序、顺序和分组；筛选枚举使用官方 SingleSelect 适配器。空库与无匹配状态分别提示，后者可清除筛选。参考 Frontend v1.59.6 内部组件的布局与语义主题；业务分类和校准入口保持原流程。独立宿主空库和弹层已观察，详细测试与限制见活动 Feature 测试报告。

筛选入口在搜索旁，打开弹层按未过滤的全量目录分页结果生成实际存在的分区选项及计数，覆盖子帧组和单文件素材。空库无选项，读取错误可重试；大库需读取全部页，性能未做压力验证。

配置页新增存储位置的文件夹选择面板通过受信本机目录浏览接口读取 ComfyUI 宿主目录，选择后填入绝对路径。登记仍由后端校验。隔离 HTTP 和组件检查已执行，真实宿主与跨平台行为待验。

存储位置目录选择面板每次选择一个目录并填入表单；不同磁盘的位置可分别添加。真实双盘宿主验证待执行。

存储位置目录选择现为模态弹窗，显示磁盘入口、面包屑和跨位置选择列表。继续使用受信本机目录浏览接口；组件验证已执行，真实宿主和跨平台表现待验。

项目树提供添加已登记素材入口，复用素材库搜索与分区筛选，显示目标逻辑路径，跨类型多选保留选择并标记已加入。批量引用一次原子提交，失败保留选择，每次最多 100 项。

项目树工具栏仅保留搜索，空白区右键创建项目，项目和文件夹右键新建文件夹及添加素材，素材右键对应父文件夹。重命名可失焦保存，新建失焦取消；键盘支持上下文菜单，不显示行尾省略号。

一次性操作通知使用宿主 toast 适配入口；可恢复错误和详情保留在页面。


素材侧栏有统一类型导入入口，校准主帧在主帧导入或编辑时填写用途与参数。子帧组复制可选多盘，预检后上传并支持续传。校准绑定失败可从任务回执重试或在组详情补绑。项目页读取 /catalog/projects，新写入使用逻辑树。

导入和编辑共用 CaptureFields；主帧和子帧组均可填写拍摄参数，像素合并及读出模式位于更多参数，设备摘要展示所选或历史快照。

素材导入和编辑提示全库名称唯一，后端 ASSET_NAME_CONFLICT 在中英文显示重名错误。

侧栏全局任务框位于节点、素材和设置视图之外，查询并展示导入及迁移任务；展开与清除状态限浏览器会话，完成和失败使用宿主通知。暂停的复制直传任务可从任务框打开恢复页，近期取消任务可查看已有错误。真实宿主验收待执行。

项目详情按后端返回的资源类型打开历史独立校准主帧。项目添加失败保留勾选并就地展示错误。

目录详情注销提交该详情读取的版本。过期操作保留页面和素材登记。

项目删除使用影响预览令牌。组详情先读摘要，展开才分页读取成员。移除成员使用组版本。
